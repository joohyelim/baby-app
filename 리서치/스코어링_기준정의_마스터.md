# 베베덱 SafeScore — 스코어링 기준정의 마스터 (v3 통합안)

> **목적:** 어떤 성분표·영양성분표·인증정보가 새로 들어와도, **동일한 규칙으로 분석·채점**해
> 대표 등급(A~E)과 근거를 산출하는 **확장형 스코어링 표준**을 정의한다.
>
> **통합 대상**
> - ① `클린푸드.xlsx` — 게이트형 로직(제외성분 하드컷 / 착한먹거리·인증 가점)
> - ② 벤치마크 *푸드랩 SafeScore v2* — 연속점수형 로직(영양·첨가물·알레르기·연령적합성 4축 → A~E, 프로필 개인화, 점수 미반영 참고신호)
> - ③ 기존 앱 엔진 `안심 기준 정리.md §2` — base 100 · 감점/가점 · 4등급
>
> 작성 기준일: 2026-08-02

## 0. 설계 원칙 (왜 이 구조인가)

| 원칙 | 의미 |
|---|---|
| **마스터/엔진 분리** | 판단 지식(어떤 성분이 나쁜가)은 **데이터(마스터 사전)** 로, 계산 방법은 **엔진**으로 분리한다. 새 성분표가 와도 엔진은 그대로, 마스터만 늘린다. |
| **카테고리 무관 재사용** | 제외성분·착한먹거리 factor는 특정 상위카테고리에서 유래해도 **다른 카테고리에 나타나면 동일하게 적용**한다(엑셀 정의 그대로). |
| **연속점수 + 게이트 2단** | 먼저 0~100 연속점수로 A~E를 매기고(정밀), 그 위에 **하드 규칙(게이트)** 으로 상·하한을 캡한다(안전). 두 자료의 장점을 결합. |
| **정보 없음 ≠ 안심** | 전성분/영양성분 미표기는 가점 대상에서 제외하고 중립 처리. (푸드랩 유의사항·기존 엔진 §2 안전장치 동일) |
| **점수 vs 참고신호 구분** | NOVA·GMO·헥산·회수 등은 **점수에 넣지 않고** 결과화면 참고표시로만 노출. |

```
 [임의 성분표]                                              [결과]
 원재료명 ─┐                                          ┌─ 대표등급 A~E
 영양성분 ─┤─▶ ②파서/노멀라이저 ─▶ 표준플래그 ─▶ ③엔진 ─┤─ 0~100 점수
 인증마크 ─┘        │                    ▲               ├─ ✓안심/✕걱정 근거
                    └── ①마스터 사전 ────┘               └─ 참고신호(비점수)
```

## 1. Layer ① — 마스터 사전 (Reference Masters)

> 모든 마스터는 **카테고리 무관 공용**을 기본으로 하되, `origin`(유래 카테고리)만 메타로 보관한다.

### 1-1. 제외성분 마스터 (HARD-EXCLUSION) — *A·B 불가 게이트*
꼭 피해야 할 물질. **1개라도 검출되면 등급 상한 C** (아래 §3 게이트 G3).

| 성분(정규명) | 별칭/표기변형 | 위험등급 | origin |
|---|---|---|---|
| 아질산나트륨 | 발색제, 아질산Na | high | 가공육 |
| 인산염류(결착제·발색보조) | 폴리인산나트륨, 결착제 | high | 가공육·수산 |
| 인산염(산도조절 미량) | 산도조절제(인산나트륨) | medium | 유제품(치즈 등) |
| 합성착색료(타르색소) | 적색40호, 황색4/5호, 청색1호 등 | high | 공용 |
| 카라멜색소 III/IV | 카라멜색소 | medium | 소스·주스 |
| 합성향료 | 향료(합성) | medium | 공용 |
| 합성보존료 | 소르빈산, 안식향산, 프로피온산칼슘 | high | 공용 |
| 합성감미료 | 아스파탐, 수크랄로스, 아세설팜K | medium | 과자·주스 |
| 카라기난 | — | medium | 유제품·두유 |
| HFCS/액상과당 | 고과당옥수수시럽, 결정과당 | medium | 주스·과자 |
| BHA/BHT/TBHQ | 산화방지제(합성) | high | 오일·과자 |
| 경화유/부분경화유 | 쇼트닝, 마가린, 트랜스지방 | high | 빵·과자 |
| MSG(L-글루탐산나트륨) | 향미증진제 | medium | 소스·간편식 |
| 합성 계면활성제 | SLES/SLS | high | 세제(LIFE) |
| EDTA / 형광증백제 / 염소계 표백제 | — | high | 세제(LIFE) |

> **분류 원칙(확정):** 제외성분은 **high/medium 위험만** 등재한다. 여기에 있으면 **1개라도 검출 시 C 캡**(§3 G3, 사용자 확정 규칙).
> **[T3 튜닝] 인산염 목적별 분리:** 동일 「인산염」이라도 **가공육 결착제·발색보조(다량)=high**, **치즈 등 산도조절제(미량)=medium**. 실데이터 검증에서 인산염을 일괄 high 처리하니 *산도조절제만 든 유기농 아기치즈*가 D로 추락(캡보다 낮음) → 미량 산도조절 인산염을 medium으로 낮추자 유기농 치즈가 C대로 정상 복귀(무인증 제품만 D 잔류).
> **저위험 항목은 제외성분에서 제외** → 아래 「감점/참고신호」로 재분류(C 캡 미적용, 감점만):

| 저위험(캡 없음) | 처리 | origin |
|---|---|---|
| 팜유/팜핵유/팜경화유 | 첨가물축 감점 −7 + 참고신호 | 빵·과자·튀김 |
| 변성전분 | 첨가물축 감점 −7 | 두부·간편식 |
| 헥산 추출유 | 감점 −7 + 참고신호(💧 헥산 용매) | 오일 |

> 데이터 소스: 엑셀 B열 「제외성분」 + 식품첨가물 공전 + 푸드랩 자체 첨가물 DB(JECFA/EFSA/IARC).
> **위험등급→감점**은 §2 첨가물축에서 사용, **제외성분 검출여부→C캡**은 §3 게이트에서 사용(이중 활용).

### 1-2. 착한먹거리 마스터 (GOOD-TO-HAVE) — *가점 + A 승격조건*
"좋은 이유"를 설명하는 대표 factor. 엑셀 E열(150여 항목)을 아래 **factor 유형**으로 정규화한다.

| factor 유형 | 판정 규칙(예시 매칭어) | 배점 | 비고 |
|---|---|---|---|
| `원물-단일성분` | "원재료 1종 · 부재료 미미(예: 닭가슴살 100%, 쌀 100%)" | **+10** | **F6 예외 전용** — 무인증도 A− 도달 가능(§3-1). 가공 거의 없는 원물의 이상적 형태 |
| `무첨가-핵심` | "무첨가/무첨가물/첨가물 0/보존료 0/합성조미료 없음/n무" | +3 | 제외성분 부재를 명시적으로 표방 |
| `무염·저염` | "무염/소금무첨가/저염/나트륨 xxmg" | +3 | 영양축과 교차검증 |
| `무첨가당·저당` | "설탕무첨가/첨가당0/당류0g/자연단맛(조청·엿기름)" | +3 | |
| `단일·소수원재료` | "원재료 n개/단일 성분/블랙박스 없음" | +3 | 투명성 |
| `국산·원산지` | "100% 국산/국내산 xx%/우리밀·우리콩" | +2 | |
| `유기·자연원료` | "유기농/무농약/무항생제/자연발효/천일염" | +3 | 인증과 별개로 원료 서술 |
| `건강공법` | "냉압착/저온로스팅/동결건조/비유탕/NFC착즙" | +2 | |
| `영양강화·프로바이오` | "식이섬유/비타민·철분강화/유산균/프리바이오틱스" | +2 | |
| `트랜스지방0·건강지방` | "트랜스지방0/현미유/올리브유/버터100%" | +2 | |

> **가점 상한:** 착한먹거리 합계 **최대 +12**(F1 재보정). 단 `원물-단일성분(+10)` 은 상한 **위 별도 합산**(원물이 90점에 도달 가능하도록). 나머지 factor 합은 +12 cap.
> origin은 메타로만 보관하고, **매칭되면 카테고리 무관 적용**.

### 1-3. 인증 마스터 (CERTIFICATIONS, 전 카테고리 공용) — *가점 + A 승격조건*
엑셀 F열. 인증마크는 라벨에서 인식 → 인증번호 실검증(친환경인증=국립농산물품질관리원, 어린이기호식품=식약처).

| 등급 | 인증 | 배점 |
|---|---|---|
| **핵심(공신력 高)** | 유기가공식품, 유기축산물, USDA Organic, EU유기농(Euro-Leaf), 어린이 기호식품 품질인증 | +10 |
| **일반 유기·친환경** | 유기농, 무농약, 무항생제, 동물복지, Non-GMO, ECOCERT, IFOAM, ACO, BIO, ICEA, AB, Skal, 비건 | +7 |
| **품질·시스템** | **HACCP**, 식품명인, 전통식품, ISO, IFS, ERC, EWG 1등급, CLEAN FOOD 6-FREE, Nutri-Score A | +5 |

> **[T1 튜닝] HACCP 재분류(+10→+5):** HACCP은 **위생·안전 시스템 인증(국내 상당수 준의무)** 이라 유기·친환경 대비 변별력이 낮다. 실데이터 40종 검증에서 `기준선70+HACCP10+착한2`가 전부 **86점(B+)에 뭉치는 과밀**이 발생 → HACCP을 「품질·시스템(+5)」으로 내려 유기인증과 차등하니 B밴드가 B−/B/B+로 정상 분산됨(§7 튜닝로그).

> **가점 상한:** 인증 합계 **최대 +18**(§2 공식과 일치). 동일 계열 중복(예: 유기농 3중인증)은 **최고점 1개만** 인정.

### 1-4. 영양 기준 마스터 (0~24개월 3구간 × 상한) — *영양축* · **실측치 확정**
스코프를 **앱 타깃 0~24개월**로 한정하고 **3구간**으로 세분. 출처: **KDRI 2025**(나트륨 AI/UL, 당류 에너지%) + **WHO/미국 식이지침 2025**(2세 미만 첨가당·나트륨 0 원칙, 12개월 미만 꿀 금지) + **어린이 기호식품 고열량·저영양 기준**(식약처 고시, 상위 참고).

| 구간 | 나트륨(1회) | 첨가당(1회) | 트랜스지방 | 비고(연령 원칙) |
|---|---|---|---|---|
| **① 수유기 0–5m** | 무염 목표(사실상 모유·분유만) | 첨가당 0 필수 | 0 | 고형식 스코어링 대상 거의 없음. 첨가 시 즉시 강한 감점 |
| **② 이유기 6–11m** | ≤ 50mg 권장 · > 100mg 강한 감점 | **첨가당 0 필수** | 0 | WHO 무염·무당 원칙. KDRI 나트륨 AI 200mg/일 |
| **③ 유아 12–24m** | ≤ 100mg 권장 · > 200mg 감점 | 첨가당 최소(총당류 ≤ 에너지 20%) | 0 | KDRI 나트륨 AI 400mg/일·UL 800mg/일 |

**KDRI 2025 참고 원값(일일):** 나트륨 AI — 0–5m **120mg** / 6–11m **200mg** / 1–2세 **400mg**(UL **800mg**). 당류 — 총당류 ≤ 에너지 **20%**, 첨가당 ≤ **10%**(단, **2세 미만은 첨가당 자체를 권장하지 않음**). 트랜스지방(인공) — 가능한 **0**.

**⚠️ 지방·포화지방 원칙(중요, 흔한 오류 방지):** **2세 미만은 총지방·포화지방을 일부러 제한하지 않는다**(WHO·KDRI 2025 — 뇌·신경 발달에 지방 필수, 총지방 에너지 20~35% 유지, 포화지방 별도 상한 없음). → **0~24개월 영양축에서 포화지방 감점을 두지 않는다.** (엑셀이 착한먹거리로 꼽은 "진짜 버터 100%·유크림 100%·현미유" 등을 잘못 깎지 않도록.) 단 **인공 트랜스지방(경화유·부분경화유)** 은 언제나 나쁨 → 감점·제외성분 유지. 과도한 튀김·스낵은 NOVA/튀김 참고신호로만 노출.

> **핵심 원칙(연령 게이트와 연동):** **2세 미만 = 첨가당·첨가나트륨 0 지향**. 첨가당이 원재료에 명시되면(설탕·물엿·시럽·농축과즙 등) 영양축 강한 감점 + §1-6 연령게이트.
> 라벨에서 영양성분표 **미인식 시 영양축은 중립값(감점 0)** 처리(정보 없음≠나쁨). 자연당(과일 본연)은 첨가당으로 보지 않음.

### 1-5. 알레르기 마스터 (식약처 표시대상 22종 + 별칭) — *최우선 게이트*
**알류(가금류)·우유·메밀·땅콩·대두·밀·고등어·게·새우·돼지고기·복숭아·토마토·아황산류·호두·닭고기·쇠고기·오징어·조개류(굴·전복·홍합 포함)·잣** (식품표시기준, 총 22종). 라벨 별칭·교차오염("~함유·같은 제조시설") 포함.
프로필에 등록한 알레르기가 원재료에서 탐지되면 §3 게이트 G1로 **전체 등급 우선 강등**.

### 1-6. 연령 적합성 마스터 (0~24개월) — *연령 게이트/감점* · **신설**
프로필 월령에 따라 자동 적용. 출처: WHO 영유아 이유 지침 · 식약처 · 미국 식이지침 2025.

| 규칙 | 대상 구간 | 효과 |
|---|---|---|
| **꿀·프로폴리스 금지** | 0–11m (12개월 미만) | 유아 보툴리누스증 위험 → **부적합(등급 상한 강등)** |
| **첨가당 0** | 0–24m (2세 미만) | 첨가당 검출 시 영양축 강감점 + 연령부적합 표시 |
| **첨가나트륨/무염** | 0–11m | 소금 첨가 검출 시 강감점 |
| **생우유(액상) 주음료 부적합** | 0–11m | 12개월 이후 허용(참고표시) |
| **질식위험 형상**(통견과·단단한 알갱이 등) | 0–24m | 참고신호 |
| **고형식 적합성** | 0–5m 고형식 부적합 / 6m~ 단계적 | 구간별 적합성 안내 |

> 연령 게이트는 §3 게이트에 **G0(연령 부적합)** 로 편입 — 알레르기(G1) 다음 우선순위로 강등 처리.

## 2. Layer ③ — 연속점수 엔진 (0~100)

프로필별 가중치 `w`로 4축 서브점수를 가중합. (개인화: 나이/알레르기/무첨가·투명성 선호)

> **⚠️ 기준선 재보정(F1 수정, 확정):** 초기안(기준선 100 + 착한+15/인증+20)은 시뮬레이션에서 **대부분 제품이 100에 포화**되어 ± 마크가 무의미해지고(무인증·풀인증 모두 A+), 영양 감점이 가점에 상쇄됐다.
> → **기준선 70**(감점 없는 평범한 표기제품의 기본점)로 낮추고 **가점 폭 축소(착한 +12 / 인증 +18)**. 재검증 결과 A+(풀인증)·A−(근거약함)·B(무인증) 해상도 복원.

```
SafeScore(raw) = 70                          # 기준선(재보정)
   − 첨가물축 감점 Σ penalty(risk)         # 고 −25 / 중 −15 / 저 −7
   − 영양축 감점  Σ nutritionPenalty        # 축 합계 최대 −40
   + 착한먹거리 가점 Σ good  (cap +12)
   + 인증 가점       Σ cert  (cap +18)
   → clamp(0, 100)
```

- **첨가물축:** 제외성분/위험첨가물 검출 시 위험등급별 감점(§1-1). 동일 성분 중복은 1회.
- **영양축:** 항목별 감점, 축 합계 최대 −40. 미인식=0. 구체식(1회 제공량, 프로필 구간 §1-4):
  - `나트륨`: 초과분 비례 감점 `−min(20, 20 × (Na − 구간권장) / 구간권장)`, 구간권장 미만=0.
  - `첨가당`: **2세 미만(0~24m 전 구간) 첨가당 > 0 → −25**(F2 수정: 12–24m도 2세 미만이므로 첨가당 0 원칙 적용).
  - **첨가당 판정(F3 수정):** 총당류만 주어진 경우 자연당과 구분 불가 → **원재료명에 설탕·물엿·시럽·과당·농축과즙 등이 있을 때만 첨가당으로 간주**. 원물(쌀·과일) 유래 당은 감점·게이트 대상 아님.
  - `트랜스지방`: **인공 트랜스지방(경화유)** `> 0 → −15`.
  - `포화지방`: **0~24개월은 감점 없음**(WHO/KDRI: 2세 미만 지방 비제한). 과도 튀김·스낵은 참고신호로만.
- **가점:** 전성분 미표기 제품은 `무첨가` 계열 가점 **불인정**(정보 없음≠안심).

### 2-1. 점수 → 대표등급 (A~E + ± 마크) — **확정**
5등급(A~E)을 채택하고, **A·B·C에는 밴드 내 위치로 ± 마크**를 부여한다. D·E는 flat(마크 없음).

| 등급 | 밴드 | − | 기본 | + | 색 |
|---|---|---|---|---|---|
| **A** | 90–100 | A− 90–93 | A 94–96 | A+ 97–100 | 🟢 |
| **B** | 75–89 | B− 75–79 | B 80–84 | B+ 85–89 | 🟩 |
| **C** | 60–74 | C− 60–64 | C 65–69 | C+ 70–74 | 🟡 |
| **D** | 40–59 | — | D | — | 🟠 |
| **E** | 0–39 | — | E | — | 🔴 |

> **± 의 의미(자동 정합):** 인증·착한먹거리 가점이 이미 점수에 반영되므로, **밴드 상단 = 핵심인증+착한먹거리 풍부(A+)**, **밴드 하단 = 조건은 충족했으나 인증이 일반등급뿐/근거 약함(A−)** 이 별도 로직 없이 성립한다. 점수라는 단일 원천으로 일관.
> 코드 반영 시 `SafetyGrade`는 A~E 레터로, 표시용 `GradeDisplay = letter + sign(+/−/'')`로 분리(§5).
>
> **± 밴드 컷(확정):** 각 밴드를 대략 3등분(A 90–93/94–96/97–100, B 75–79/80–84/85–89, C 60–64/65–69/70–74). 재보정(기준선 70) 기준 실제 제품이 밴드 전반에 분포하므로 현행 컷 유지.

### 2-2. 프로필 개인화 가중치 `w` — **확정**
벤치마크 핵심(*"같은 제품도 프로필에 따라 다른 SafeScore"*)을 반영. **기본 프로필 = 모두 ×1.0(중립)** 이라 비개인화 사용자도 동일 규칙으로 채점되고, 프로필 설정 시 아래 배수만 적용한다.

| 프로필 요소 | 조정 대상 | 가중치 `w` | 비고 |
|---|---|---|---|
| **월령**(자동) | 영양 밴드 + 연령 게이트 | 구간 선택 | §1-4·§1-6 (이미 반영) |
| **알레르기**(등록) | G1 게이트 | on/off | §3 G1 (이미 반영) |
| **무첨가 민감도** 강/중/약 | 첨가물축 감점 | ×1.3 / ×1.0 / ×0.8 | 민감할수록 첨가물 감점 강화 |
| **인증·유기농 중시** on/off | 인증 가점 | ×1.2 / ×1.0 | 중시하면 인증 가점 강화 |
| **원료 투명성 중시** on/off | 미표기·복합원료 감점 | ×1.3 / ×1.0 | 블랙박스 원료·미표기 페널티 강화 |
| **저염 민감**(신장 우려 등) on/off | 나트륨 감점 | ×1.3 / ×1.0 | |

> **안전 가드:** 개인화 배수는 **감점·가점의 크기만** 조정하고 **게이트(G0~G3)는 불변**(안전 규칙은 취향으로 완화 불가). 개인화로 인한 등급 변동은 **±1 등급 이내**로 클램프(취향이 A↔E를 뒤집지 않게). 미설정 프로필 = 전부 ×1.0 → 「기본 등급」.
> 결과화면은 **「기본 등급」과 「나에게 맞는 등급」** 을 함께 표기 가능.

## 3. Layer ③ — 게이트 규칙 (등급 상·하한 override)

연속점수로 계산한 등급 위에, **하드 규칙**을 우선순위 순으로 적용한다. (엑셀 게이트형 로직의 핵심)

| 순위 | 게이트 | 조건 | 효과 |
|---|---|---|---|
| **G1** | 🔴 알레르기 | 프로필 알레르기 성분 탐지 | **전체 등급 최우선 강등**(경고 배지 + 최대 D 이하). 점수 무관. |
| **G0** | 🔴 연령 부적합 | 꿀(0–11m)·첨가당(0–24m)·첨가나트륨(0–11m) 등 §1-6 위반 | **연령 부적합 강등**(알레르기 다음 우선). 12개월 미만 꿀=차단 수준. |
| **G2** | 🔴 회수·판매중지 | 식품안전나라 회수/판매중지 매칭 | 등급 강등 + 경고. |
| **G3** | 🟠 제외성분 캡 | 제외성분(§1-1, **high/medium만**) **≥1 검출** | **등급 상한 C+** (A·B 불가, C 밴드까지만). 점수 90이어도 C 밴드로 클램프. 저위험 항목은 캡 미적용(감점만). |
| **G5** | 🟠 전성분 미표기 캡 (F5 수정) | `hasFullIngredientList = false` | **등급 상한 C** (정보부족=불확실 → B 이상 불가). |
| **G4** | 🟢 A 승격조건 | 아래 조건 충족 | A 확정. 미충족 시 **최대 B**. |

### 3-1. A vs B 구분 규칙 (사용자 고민 해소안)
> "제외성분 없음"만으로는 A가 아니다. **좋은 이유가 증명(착한먹거리 + 인증)** 되어야 A.
> **인증은 필수 조건**으로 확정 — 인증 자체가 중요한 판별 팩터이기 때문.

**A 조건 (전부 충족):**
1. 제외성분 **0개** (G3 미발동)
2. 착한먹거리 factor **≥1** 매칭 (§1-2)
3. 인증 **≥1** 보유(실검증 통과) (§1-3) ← **필수, 예외 없음(확정)**
4. 연속점수 **≥90**

**A 예외 — 원물 단일성분 (F6 수정, 확정 · T2 튜닝 보강):**
- **원물 단일성분(가공 거의 없음, 예: "닭가슴살 100%", "쌀 100%")** 은 인증이 없어도 **A− 까지 허용**.
- 조건: 원재료 실질 1종(부재료 미미) + 제외성분 0 + 첨가당·첨가나트륨 0 + 나트륨 구간 이내.
- **[T2 튜닝] 점수 하한(양의 게이트) 부여:** 위 조건을 **모두 충족한 청정 원물**은 착한먹거리 factor 매칭이 적어도 **점수 하한 90(A− 진입)** 을 보장한다(C 캡과 대칭인 「양의 게이트」). 실데이터 검증에서 *무염 구운김·동결건조 사과칩*처럼 마케팅 factor가 적은 순수 원물이 +10 가점만으로 90에 못 미쳐 B+에 머무는 문제를 해소. 단 **A− 상한**(인증 제품과 차등, A/A+ 불가).

**등급 결정 요약:**
| 상황 | 대표등급 |
|---|---|
| 제외성분 0 + 착한먹거리 + 인증 + 점수 ≥90 | **A** (인증·근거 풍부 → A+) |
| 원물 단일성분 + 무첨가·무염 + 점수 ≥90 (무인증) | **A−** (예외) |
| 제외성분 0 + (착한먹거리 or 인증) 있으나 A조건 미달 / 점수 75–89 | **B** |
| 제외성분 ≥1 (캡) · 전성분 미표기 · 점수 60–74 | **C** |
| 위험첨가물·영양초과 다수 (점수 40–59) | **D** |
| 점수 0–39 또는 알레르기/연령/회수 강등 | **E** |

## 4.5. 노출·큐레이션 정책 (Surface Policy) — **확정**

> **핵심 문제:** 베베덱은 *큐레이션* 앱이므로 좋은 상품을 먼저 노출해야 한다. 그러나 저등급(C/D/E)을 **전부 숨기면** 안 된다 — 예로 **"아기 소세지"(가공육)** 는 아질산나트륨·인산염 때문에 **구조적으로 대부분 C 이하**라, 숨기면 검색 결과가 비어 앱이 무용지물이 된다. (벤치마크 유의사항: *"낮은 SafeScore = 위험한 제품 아님, 상대적 비교 지표"*)
> → **숨기지 말고 맥락(surface)별로 차등** 노출한다.

| 화면(surface) | 노출 정책 |
|---|---|
| **큐레이션 진열** (홈·월령추천·"골라줌") | **A·B만 노출** ("꼭 필요한 것만 골라줘" 컨셉) |
| **검색 결과** | **전 등급 노출 + A→E 랭킹**. C 이하는 **시각적 디엠퍼사이즈**(회색/접기) + 상단에 **"더 안심되는 대안" 카드** |
| **개별 상세 / 스캔** | **실제 등급 그대로** (사용자가 가진 제품 확인 → 투명성) |

**부가 장치**
- **대안 추천:** C/D/E 제품 조회 시 **동일 하위카테고리 최상위(A/B)** 를 "이 대신 이거 어때요?"로 추천.
- **카테고리 적응형:** 해당 카테고리에 A/B가 **하나도 없으면** "이 카테고리 **베스트**" 라벨로 최선 제품 정직하게 노출(빈 결과 금지).
- **랭킹 규칙:** ① 등급 desc(A→E) → ② 연속점수 desc → ③ 인증·착한먹거리 factor 수 desc → ④ 참고신호 적은 순.
- **빈 결과 가드:** 필터로 0건이 되면 자동으로 "베스트 N개"로 폴백.

- ✅ **[F2 수정] 12–24m 첨가당:** 2세 미만 전 구간 첨가당 0 원칙(−25/G0) 적용.
- ✅ **[F3 수정] 첨가당 판정:** 원재료에 설탕·시럽·농축과즙 있을 때만 첨가당 처리(자연당 제외).
- ✅ **[F4 수정] 제외성분 분류:** 저위험(팜유·변성전분·헥산)은 제외성분에서 제외, 감점/참고신호로.
- ✅ **[F5 수정] 미표기 캡:** 전성분 미표기 시 등급 상한 C (G5).
- ✅ **[F6 수정] 원물 예외:** 원물 단일성분은 무인증도 A− 허용. 전용 가점 +10(가점 상한 위 별도 합산)으로 90점 도달 가능하게 확정.
- ✅ **[확정] 노출·큐레이션 정책:** 진열 A·B만, 검색 전등급 랭킹+대안추천, 상세 실등급(§4.5).

- ✅ **[확정] 개인화 가중치 `w`:** 기본 ×1.0 중립 + 선호별 배수 테이블, 게이트 불변·±1등급 클램프(§2-2).

**실데이터 재검증 튜닝로그 (실제 한국 영유아 제품 40종 모델링 검증):**
- ✅ **[T1] HACCP 인증 재분류:** 핵심(+10)→품질·시스템(+5). `기준선70+HACCP10+착한2=86(B+)` 과밀(14/40) 해소 → B밴드 B−/B/B+ 정상 분산(§1-3).
- ✅ **[T2] 원물 청정품 점수 하한 90:** 순수 원물(무염김·사과칩 등)이 factor 부족으로 A− 못 가던 문제 → 청정 조건 충족 시 하한 90 양의 게이트(§3-1).
- ✅ **[T3] 인산염 목적별 분리:** 결착제·발색보조(다량)=high, 산도조절제(미량)=medium. 유기농 아기치즈 D→C 복귀(§1-1).
- ✅ **[T4] 분포 정상화 확인:** T1~T3 반영 후 A9·B14·C5·D7·E5(40종) 종형 분포, C밴드(C−/C/C+) 채워짐. 진열대상 A·B=57%로 큐레이션 물량 충분.
