# SafeScore ⑥ 기구군 (v1.0)

- 적용 규제: 어린이제품 안전특별법 + 전기용품 안전관리법
- 품목: 젖병소독기, 아기욕조, 체온계, 콧물흡입기, 습도계
- 소속 타일: 젖병·식기(소독기) / 씻기기(욕조) / 케어(체온계·콧물흡입기, ⏳ 논의 필요) / 입히기·재우기(습도계, ⏳ 논의 필요)
- 원칙: 전성분표가 없는 기기류라 성분 감점이 불가. 인증·리콜·정보 공개만으로 판정 (맘가이드도 이 품목군은 미커버, 베베덱스 차별점)

## 1. 등급 판정 (점수 없음, 조건으로 직행)

성분 채점이 없어 70점 기준선 계산식 미적용. 4단계 flat, ± 없음 (심플 카테고리는 심플하게)

| 등급 | 조건 | 1차 노출 |
|---|---|---|
| A | 의무 KC 보유(전기제품은 이중 KC) + 리콜 없음 + 재질·제조국·AS 공개 + 식품 접촉부 BPA-free | 노출 |
| B | 의무 KC 보유 + 리콜 없음. 정보 공개 일부 미흡 | 노출 |
| C | KC는 있으나 재질·정보 불명 | 비노출 |
| D | KC 미표시 또는 진행 중 리콜 | 비노출 |

공통 규칙과의 관계

| 규칙 | 이 군의 적용 |
|---|---|
| 진행 중 리콜 | 해당 모델은 즉시 D + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| 정보 없음 ≠ 안심 | 재질·제조국 미공개는 A 불가 (B 또는 C) |
| 인증 3단 구분 | 이중 KC(전기 + 어린이제품)가 최상위 신뢰. 단일 KC는 그 다음 |

## 2. 품목별 확인 항목

| 품목 | 의무 인증 | 추가 확인 |
|---|---|---|
| 젖병소독기 | 전기용품 KC + 어린이제품 KC (이중) | 젖병 접촉부 재질, UV 램프 오존 발생 여부 |
| 아기욕조 | 어린이제품 KC | 재질 (PP 등), 미끄럼 방지 |
| 체온계 | 의료기기 인증 (식약처) | KC가 아닌 의료기기법 적용. 인증번호 표시 확인 |
| 콧물흡입기 | 의료기기 인증 (식약처) | 흡입부(코 접촉) 재질 |
| 습도계 | 전기식은 전기용품 KC | 아날로그식은 의무 인증 없음. 정보 공개로만 판정 |

- 체온계·콧물흡입기는 의료기기라 어린이제품 KC 대신 식약처 의료기기 인증을 의무 인증으로 간주
- 아날로그 습도계처럼 의무 인증 자체가 없는 품목은 A 불가, 최고 B (정보 공개 충실 시)
- 월령별 차등: 미도입. 성분 채점이 없는 군이라 월령별 민감 성분 개념 자체가 비적용. 제품별 권장 월령(제조사 표기)만 노출 필터로 사용

## 3. 판정 예시

UV 젖병소독기, 전기 KC 보유, 어린이제품 KC 미표시, 리콜 없음, 재질 공개

- 의무 인증: 이중 KC 중 1개 누락
- 결론: C (KC 일부 보유이나 의무 인증 불완전). 1차 비노출

적외선 체온계, 의료기기 인증번호 표시, 리콜 없음, 제조국·AS 공개

- 의무 인증 충족 + 정보 공개 충실
- 결론: A. 큐레이션 노출

## 4. 인증별 보증 내용

| 인증 | 내용 |
|---|---|
| 이중 KC | 전기용품 KC(감전·화재) + 어린이제품 KC(유해물질·물리 안전) 둘 다 보유. 전기 육아용품의 최상위 |
| 어린이제품 KC | 어린이제품 안전특별법 기준. 유해물질·물리적 안전 |
| 전기용품 KC | 전기용품 안전관리법 기준. 감전·화재 안전 |
| 의료기기 인증 | 식약처 의료기기법 기준. 체온계·콧물흡입기의 성능·안전 |
