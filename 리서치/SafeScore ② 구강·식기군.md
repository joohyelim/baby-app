# SafeScore ② 구강·식기군 (v1.0)

- 적용 규제: 식품위생법 기구·용기·포장 (용출 기준)
- 품목: 젖병, 젖병솔, 빨대컵, 그릇·식판, 스푼, 치발기, 치약
- 소속 타일: 젖병·식기 / 씻기기 / 놀이·배움(치발기)
- 원칙: 입에 들어가는 물건이라 성분보다 재질과 용출이 핵심. 치약은 의약외품이나 구강 접촉이라 이 군에서 채점. 치발기는 놀이 장면 소속이어도 젖병과 같은 기준으로 보수 채점

## 1. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 가점은 인증 최대 +18, 안전소재 등 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 재질 검출 | −25 또는 −15 항목 1개 이상이면 점수와 무관하게 최고 C+ |
| 의무 인증 미표시 | 식품용 적합 표시 없으면 최고 C+ |
| 재질 미표기 | 재질 정보 없으면 최고 C |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 재질 0 + 안전소재 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| A 예외 | 단일 안전소재(스테인리스 304/316, 강화유리)는 무인증도 A−까지 |
| 정보 없음 ≠ 안심 | 재질 미표기 제품은 BPA-free 등 가점 불인정 |

## 2. 재질 3층 구조 ⏳ 플라스틱 처리 전체가 논의사항

아래 3층 구조는 초안. 위험 재질 감점(법·근거 명확)은 유지 전제이나, 일반 플라스틱(중립 재질)의 처리 방식은 확정 아님

| 층 | 재질 | 처리 (초안) |
|---|---|---|
| 위험 재질 | BPA/PC, PVC, 멜라민(가열용), PFOA 코팅 | 감점 + 등급 상한 C+ |
| 중립 재질 ⏳ | PP, Tritan, PET, PE 등 일반 식품용 플라스틱 | 노출 경로 2분법 적용 (아래). 비구강·비가열이면 무감점·무가점, 구강·가열 제품은 소폭 감점 여부만 잔여 논의 |
| 가점 재질 | 식품용 실리콘 100%, 스테인리스 304/316, 강화유리, PPSU | +10 |

중립 재질의 노출 경로 2분법 (한솔 확정 방향, 2026-08)

- 재질 축은 제품의 노출 경로에 따라 다르게 적용. 일률 적용하지 않음
- 구강 접촉·가열 제품 (젖병, 빨대컵, 치발기, 스푼, 전자레인지·열탕 대상 그릇·식판): 물고 빨고 가열되어 용출 노출이 실제로 일어나는 제품. 재질 축 온전히 적용 — 가점 재질(실리콘·스테인리스·유리·PPSU) +10이 맞고, 위험 재질 감점도 그대로
- 비구강·비가열 제품 (젖병솔 손잡이, 상온 전용 보관 용기 등 입에 닿지 않는 품목·부위): 재질이 일반 플라스틱이어도 가점·감점 모두 없음 (재질 축 중립화). 인증 가점만 작동
- 논리: 용출은 노출 경로가 있어야 위험이 됨. 입에 안 들어가고 가열도 안 되는 플라스틱에 감점을 주는 것은 근거 없는 감점 원칙과 충돌, 반대로 가점을 주는 것도 안전 기여가 없어 부적절

논의 쟁점 (화요일 안건)

- 중립 재질 소폭 감점(−7) 대안의 잔여 범위: 위 2분법으로 비구강·비가열 제품은 0으로 정리됨. 남는 논의는 구강 접촉·가열 제품에 쓰인 중립 재질(PP 젖병·이유식기 등)에 한해 보수 감점을 줄지 여부. PP·Tritan은 식품용 적합 기준 통과 시 위험 근거가 없다는 반론은 유효
- 미세플라스틱: PP 젖병 열탕 소독 시 방출 연구 존재하나 규제 기준·건강 영향 근거 미확립. 보수 원칙을 적용해 감점할지, 근거 축적까지 ⚠️ 안내(열탕 소독 시 미세플라스틱 방출 가능)만 할지
- 멜라민 특칙: 가열 용도만 −15로 좁힌 현 초안 유지 여부 (상온 사용 전제까지 감점하면 식판 대부분 탈락)
- PPSU 위치: 플라스틱임에도 가점 재질에 둔 현 초안 유지 여부 (내열성·BPA 무첨가로 젖병 표준 소재이나, 보수 원칙을 플라스틱 전체로 확장하면 재분류 필요)

## 3. 감점표

| 감점 | 재질·성분 |
|---|---|
| −25 | BPA/PC, 비스페놀류 대체물질(BPS·BPF·BPAF 등), 프탈레이트, PVC, 중금속 용출, PFOA |
| −15 | 멜라민 수지 (가열 용도 제품에 한함), 대나무·왕겨 등 식물성 분말 + 멜라민 복합소재 (용도 불문) |
| −7 | 재질 일부 불명확 (본체는 공개, 부속 미공개 등) |

- 보수 원칙 (①군과 공통, 2026-08 해외 갭 조사 반영): 국내는 허용이라도 주요 규제기관이 금지한 재질·물질은 감점
  - 비스페놀류 대체물질 −25: EU Regulation 2024/3190(2025 발효)이 BPA뿐 아니라 BPS·BPAF 등 유해성 분류된 비스페놀류까지 모든 식품접촉재료에서 금지. 국내는 젖병 BPA만 금지라 갭이 큼. BPA-free 마케팅 제품이 BPS로 대체한 경우를 잡는 행
  - 대나무·멜라민 복합소재 −15: 친환경으로 팔리는 대나무 섬유 식기 다수가 실제로는 멜라민 수지 결합재 사용. EU가 2021년 멜라민·폼알데하이드 용출 초과를 이유로 유통 금지. 국내는 명시 금지 규정 미확인. 상온에서도 용출 보고가 있어 가열 한정인 순수 멜라민 행과 달리 용도 불문 감점
  - 일본 포지티브 리스트 (2020 고시, 2025 완전 시행): 식품접촉 합성수지를 승인 목록 방식으로 관리. 국내 네거티브 방식보다 엄격한 축이라 애매 재질 판단 시 보조 참고 (등재 여부를 감점 규칙으로 자동화하기는 어려워 참고 원천으로만)

## 4. 가점표

| 가점 | 항목 |
|---|---|
| +10 | 식품용 적합 + 용출시험 통과, KC (젖병) |
| +10 | 단일 안전소재: 식품용 실리콘 100%, 스테인리스 304/316, 강화유리, PPSU |
| +3 | BPA-free 명시, 재질 전체 공개 |

- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 5. 특칙

- 치발기: 완구이지만 입에 물고 빠는 시간이 길어 이 군의 용출 기준으로 채점. 완구 KC는 별도 가점 인정
- 멜라민 식판: 상온 사용은 감점 없음, 전자레인지·열탕 소독 안내가 있는 제품만 −15

## 6. 월령별 규칙

- 작동 방식: 점수·등급은 고정, 월령 축은 노출 제한과 안내로만 작동 (①군과 동일 원칙)

| 월령 | 대상 | 규칙 | 근거 |
|---|---|---|---|
| 이 나기 전 (대략 0~5개월) | 불소 치약 | 해당 월령에 비노출. 가제·구강티슈 닦기 안내 | 대한소아치과학회: 치약은 첫 이 맹출 이후부터 |
| 이 나온 후~24개월 | 불소 1,000ppm 치약 | 쌀알 크기 사용 안내와 함께 노출 | 대한소아치과학회·미국소아과학회: 맹출 직후부터 1,000ppm 쌀알 크기 권장 |
| 전 월령 | 무불소 치약 | 감점 없음, 충치 예방 가점도 없음 | 불소가 충치 예방의 핵심 성분이라는 학회 일치 견해. 무불소를 안전 가점으로 오인하지 않도록 처리 |

- 불소는 위험 성분이 아니라 용량 관리 성분. 감점 대상 아님, 월령별 사용량 안내로만 다룸

## 7. 계산 예시

PPSU 젖병, 식품용 적합 + 용출시험 통과, 재질 전체 공개

- 감점: 없음
- 가점(인증): 식품용 적합 + 용출시험 +10
- 가점(착한 요소): PPSU 단일소재 +10, 재질 전체 공개 +3 = +13 → 상한 +12 적용
- 점수: 70 + 10 + 12 = 92
- A 조건 충족 (감점 0, 안전소재, 인증, 90점 이상)
- 결론: A 구간. 큐레이션 노출

PP 이유식 그릇, 식품용 적합 표시, 용출시험 미확인, BPA-free 명시

- 감점: 없음 (PP는 중립 재질)
- 가점: BPA-free 명시 +3 (용출시험 미확인이라 +10 불가)
- 점수: 70 + 3 = 73
- 결론: C 구간. 1차 비노출. 같은 제품이 용출시험까지 공개하면 83으로 B 진입 (중립 재질은 인증 공개가 등급을 가르는 구조)
- ⏳ 이 예시의 PP 그릇은 구강 접촉 제품이라 §2 잔여 논의(구강·가열 제품의 중립 재질 소폭 감점 여부) 대상. 감점안으로 확정되면 결과 달라짐. 비구강·비가열 제품이면 2분법에 따라 현 계산 그대로 확정

## 8. 감점 재질별 위험 근거

| 재질·성분 | 이유 |
|---|---|
| BPA / PC | 대표적 환경호르몬. 국내에서 젖병 사용 금지(2012). PC는 BPA로 만든 플라스틱 |
| 프탈레이트 | 플라스틱을 말랑하게 하는 가소제. 생식·발달 영향으로 어린이제품 규제 대상 |
| PVC | 프탈레이트 가소제가 들어갈 가능성이 높은 소재 |
| 중금속 (납·카드뮴) | 신경 발달 저해, 몸에 쌓이고 배출 안 됨. 영유아는 미량도 위험 |
| 멜라민 수지 | 상온에선 안전하지만 고온에서 멜라민·폼알데하이드가 녹아 나옴. 가열 용도만 감점 |
| 비스페놀류 대체물질(BPS·BPF·BPAF) | BPA와 유사한 내분비계 교란 작용 보고. EU 2024/3190이 식품접촉재료 전면 금지, 국내는 미규제라 보수 원칙 적용 |
| 대나무·멜라민 복합소재 | 식물성 분말을 멜라민 수지로 굳힌 소재. 순수 멜라민보다 용출이 쉬워 EU 2021년 유통 금지. 친환경 표기에 가려지는 대표 사례 |
| PFOA | 과불화화합물. 코팅이 벗겨질 때 노출, 몸에 오래 잔류 |
