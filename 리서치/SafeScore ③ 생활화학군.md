# SafeScore ③ 생활화학군 (v1.0)

- 적용 규제: 생활화학제품 및 살생물제 안전관리법 (초록누리 신고)
- 품목: 세탁세제, 섬유유연제, 유아 클리너, 젖병세정제
- 소속 타일: 위생·청소 / 젖병·식기
- 원칙: 잔류가 문제. 헹군 뒤 아기 피부와 식기에 남는 것 기준
- 벤치마크: 클린푸드 세제 블록

## 1. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 가점은 인증 최대 +18, 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 또는 −15 성분 1개 이상이면 점수와 무관하게 최고 C+ |
| 초록누리 미신고 | 법정 의무 위반이라 최고 C+ |
| 전성분 미공개 | 최고 C |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 성분 0 + 착한 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| 정보 없음 ≠ 안심 | 전성분 미공개 제품은 무첨가 가점 불인정 |

## 2. 감점표

| 감점 | 성분 |
|---|---|
| −25 | CMIT/MIT, 형광증백제, 염소계 표백제 |
| −15 | SLES/SLS, EDTA, 인산염, 합성보존료 |
| −7 | 합성향료, EWG 클리닝 D·F 등급 성분, 의도적 첨가 미세플라스틱(마이크로비즈), 구형 4급 암모늄 양이온 계면활성제 (섬유유연제, 에스터쿼트 제외) |

- EWG 사용 원칙 (확정, ①군과 공통): EWG는 유해성 기준이므로 감점(위험 경고 방향)에만 사용. 공적 목록에 없는데 EWG 클리닝 D·F인 성분만 −7, 단독으로는 등급 상한 미적용. 가점(안전 보증 방향)으로는 미사용
- 해외 갭 조사 결과 (2026-08, ①②④⑤군과 같은 방식으로 확인)
  - 미세플라스틱 −7: EU Regulation 2023/2055가 세제·섬유유연제 포함 의도적 첨가 미세플라스틱을 단계 금지 (2023 발효, 품목별 2027~ 적용). 국내는 특별법 발의 단계라 갭 존재. 보수 원칙 감점
  - 구형 4급 암모늄 −7: 섬유유연제의 구세대 양이온 계면활성제. 환경 잔류성·수생독성으로 EU 평가 강화, 유럽 시장은 생분해되는 에스터쿼트로 세대 교체 완료. 에스터쿼트 사용 제품은 감점 없음
  - 보존제·향료 표시 의무: EU 세제 규정과 국내 기준 모두 알레르기 향료 0.01% 표시라 갭 작음. 신규 행 없음
  - 유아 세탁세제 해외 전용 기준: 조사 결과 없음 확정. 각국 모두 일반 화학물질 규제 준용이라 베베덱스 자체 기준(이 문서)이 그대로 차별화 지점

## 3. 가점표

| 가점 | 항목 |
|---|---|
| +7 | 초록누리 신고, 친환경 인증(환경표지), 해외 공적 에코라벨 (EPA Safer Choice, EU Ecolabel, 노르딕 스완, 블루엔젤 중 1개 이상) |
| +3 | 식물성 계면활성제(APG), 천연 세정 성분(구연산·베이킹소다·효소) |
| +2 | 1종 세척제 등급 (식기 접촉 가능) |

- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서
- EWG 클리닝 1등급 가점 제거 (확정, 2026-08): EWG는 민간단체 자체 등급이라 안전 보증(가점) 근거로 부적합. 감점 기준으로만 사용 (§2). 가점 자리는 정부·공공기관이 운영하는 해외 공적 에코라벨로 대체 — EPA Safer Choice(미국 환경보호청, 세정제 전 성분 심사 라벨), EU Ecolabel(EU 집행위), 노르딕 스완(북유럽 정부 공동), 블루엔젤(독일 정부). 모두 기관이 기준 충족을 확인하는 구조라 +7 층에 해당. 복수 보유해도 이 행은 1회만 가점

## 4. 특칙

- 젖병세정제: 식기에 직접 닿아 헹굼 잔류 위험이 커 1종 세척제 등급 미표기 시 최고 B
- 섬유유연제: 옷에 남기는 것이 목적인 제품이라 합성향료 감점을 −7이 아닌 −15로 적용
- 월령별 차등: 미도입. 세제류는 간접 접촉(잔류)이라 월령별 감수성 차이의 학술 근거 부족. 신생아기 향료 회피 선호는 무향 가점 구조로 이미 반영

## 5. 계산 예시

APG 계면활성제 유아 세탁세제, 초록누리 신고, 무형광, 합성향료 함유

- 감점: 합성향료 −7
- 가점: 초록누리 +7, APG +3 = +10
- 점수: 70 − 7 + 10 = 73
- 등급 제한 해당 없음 (−7은 상한 미적용)
- 결론: C 구간. 1차 비노출

## 6. 감점 성분별 위험 근거

| 성분 | 이유 |
|---|---|
| CMIT/MIT | 가습기 살균제 사태의 원인 물질 계열. 호흡기·피부 손상 |
| 형광증백제 | 하얗게 보이게 하는 형광물질. 피부 접촉 시 알레르기·피부염 우려 |
| 염소계 표백제 | 강한 자극성. 세탁 후 잔류하면 피부·호흡기 자극 |
| SLES / SLS | 세정력이 강한 합성 계면활성제. 잔류 시 피부 자극·건조 |
| EDTA | 금속이온 봉쇄제. 그 자체보다 다른 성분의 피부 침투를 돕는 게 문제 |
| 인산염 | 세제 보조제. 피부 자극과 수질 오염, 헹굼 후 잔류 우려 |
| 합성보존료 | 화학 보존제 총칭. 접촉성 피부염의 흔한 원인 |
| 합성향료 | 알레르기·자극 유발 가능. 세부 성분 비공개라 검증 불가 |
| EWG 클리닝 D·F 등급 | EWG Guide to Healthy Cleaning의 위험 구간. 공적 목록에 없는 성분의 안전망 역할. 민간 등급이라 −7에 그치고 등급 상한 미적용 |
| 의도적 첨가 미세플라스틱 | 세정 보조·스크럽용 마이크로비즈. 헹굼물로 배출돼 환경 잔류, EU가 세제·섬유유연제 포함 단계 금지. 국내는 입법 전이라 보수 원칙 감점 |
| 구형 4급 암모늄 계면활성제 | 섬유유연제 구세대 양이온 성분. 난분해성·수생독성으로 EU 평가 강화, 옷에 남기는 제품 특성상 피부 잔류 우려. 생분해되는 에스터쿼트는 감점 없음 |

## 7. 인증별 보증 내용

| 인증 | 가점 | 내용 |
|---|---|---|
| 초록누리 신고 | +7 | 환경부 생활화학제품 안전기준 확인·신고 제도. 세제·클리너의 기본 관문 |
| 친환경 인증 | +7 | 환경부 환경표지. 유해물질·환경성 기준 |
| 해외 공적 에코라벨 | +7 | EPA Safer Choice(미국 환경보호청)·EU Ecolabel(EU 집행위)·노르딕 스완(북유럽 정부 공동)·블루엔젤(독일 정부). 정부·공공기관이 세정제 성분·환경성 기준 충족을 확인하는 라벨 |
| 1종 세척제 | +2 | 식약처 세척제 구분 중 식기·야채 세척 가능 등급 |
