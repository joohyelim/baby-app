# SafeScore ④ 섬유·위생용품군 (v1.0)

- 적용 규제: 어린이제품 안전특별법 + 위생용품 관리법
- 품목: 배냇저고리, 속싸개·손싸개, 가제 손수건, 침구, 기저귀
- 소속 타일: 입히기·재우기 / 위생·청소(기저귀)
- 원칙: 피부에 종일 닿는 것. 소재와 가공 잔류물 기준

## 1. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 가점은 인증 최대 +18, 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 또는 −15 항목 1개 이상이면 점수와 무관하게 최고 C+ |
| 의무 KC 미표시 | 어린이제품 KC 없으면 최고 C+ |
| 혼용률 미표기 | 소재 정보 없으면 최고 C |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 성분 0 + 착한 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| A 예외 | 순면 100% 단일 소재는 무인증도 A−까지 |
| 정보 없음 ≠ 안심 | 혼용률 미표기 제품은 소재 가점 불인정 |

## 2. 감점표

| 감점 | 성분·요소 |
|---|---|
| −25 | 폼알데하이드, 아조염료, 납·카드뮴, 형광증백제 |
| −15 | pH 부적합 (약산성~중성 이탈), 향료 첨가 기저귀, PFAS 방수·방오 가공, 브롬계·유기인계 난연제 |
| −7 | 혼용률 미표기, 니켈 용출 금속 부품 (스냅단추·지퍼, EU 기준 초과 시) |

- 보수 원칙 (①②⑤군과 공통, 2026-08 해외 갭 조사 반영): 국내 기준이 없거나 느슨해도 주요 규제기관이 금지·경고한 물질은 감점
  - 향료 첨가 기저귀 −15: 프랑스 ANSES 기저귀 유해물질 보고서(2019)가 향료(릴리알·HHCB 등)를 핵심 위험으로 지목, 이후 유럽 시장은 무향이 표준. 국내 위생용품 기준에는 기저귀 향료 규제 없음. 24시간 밀착 + 점막 인접 제품이라 ①군 착향제보다 엄격하게 감점
  - PFAS −15: 미국 캘리포니아 AB 652(2023 발효)가 아동용품 PFAS 금지, EU도 광범위 제한 진행. 국내 K-REACH는 등록 관리 수준. 기저귀·방수요·침구 방수 가공 확인 대상. ⑤군 PFAS 행과 동일 원칙
  - 난연제 −15: 브롬계(PBDE)·유기인계(TCEP·TDCPP) 난연제는 EU POPs 제한·미국 주 금지 확대. 국내 아기 침구 난연제 기준 부재. 첨가형 난연제 표기 제품 감점
  - 니켈 −7: EU REACH가 피부 접촉 금속의 니켈 용출 기준(0.5μg/cm²/주) 운영, 국내 어린이제품 기준에는 없음. 접촉성 피부염 원인이라 금속 부품 있는 의류 확인
  - 은나노(나노실버) 항균 가공: 감점 없이 ⚠️ 표시 (해외 평가가 엇갈려 감점 근거 부족. 항균 마케팅을 가점으로 오인하지 않도록 가점도 없음)
  - EU REACH 2018/1513 (의류·섬유 CMR 33종 제한, 2020 발효): 국내 KC와 겹치는 항목이 많아 신규 행은 없음. 애매 물질 판단의 보조 원천으로 사용

## 3. 가점표

| 가점 | 항목 |
|---|---|
| +10 | OEKO-TEX Class I, 순면 100% 단일 소재 |
| +7 | GOTS, KC 안전확인, 위생용품 적합 (기저귀) |
| +3 | 무형광·무염색 명시, 천연펄프 (기저귀) |

- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 4. 특칙

- 기저귀: 24시간 밀착 + 점막 인접이라 형광증백제 검출 시 등급 상한 C가 아닌 즉시 D
- 배냇저고리·속싸개: 신생아 직접 접촉이라 염색 제품은 무염색 대비 가점 없이 채점 (감점은 아님)
- 월령별 차등: 이 군은 미도입. KC 유해물질 기준 자체가 36개월 이하 단일 기준이고, 신생아기 무염색 선호는 가점 구조로 이미 반영. 월령별로 감점을 달리할 학술 근거 부족

## 5. 계산 예시

순면 100% 배냇저고리, KC 안전확인, 무형광 명시, OEKO-TEX 없음

- 감점: 없음
- 가점: 순면 100% +10, KC 안전확인 +7, 무형광 +3 = +20
- 점수: 70 + 20 = 90
- A 조건 충족 (감점 0, 착한 요소, 인증, 90점)
- 결론: A−~A 구간. 큐레이션 노출

## 6. 감점 성분별 위험 근거

| 성분·요소 | 이유 |
|---|---|
| 폼알데하이드 | 1군 발암물질. 새 옷의 접착제·수지 가공에서 잔류 |
| 아조염료 | 섬유 염색용. 일부가 몸에서 발암성 물질(아릴아민)로 분해 |
| 납·카드뮴 | 신경 발달 저해, 몸에 쌓이고 배출 안 됨. 스냅단추·프린트에서 검출 |
| 형광증백제 | 하얗게 보이게 하는 형광물질. 기저귀·가제에서 검출 이슈 반복 |
| pH 부적합 | 피부 접촉 섬유의 안전 기준(약산성~중성) 이탈. 피부 자극 |
| 향료 첨가 기저귀 | ANSES 2019 보고서가 기저귀 향료를 위험 요인으로 지목. 점막 인접 부위 상시 접촉이라 알레르기·자극 위험이 화장품보다 큼 |
| PFAS | 과불화화합물. 잔류·축적성, 방수 가공에 사용. 캘리포니아 아동용품 금지·EU 제한 진행 |
| 브롬계·유기인계 난연제 | 호르몬 교란·신경 발달 영향 보고. EU POPs 제한, 미국 주 금지 확대. 침구 첨가형 난연제가 문제 |
| 니켈 (금속 부품) | 접촉성 피부염의 대표 원인 금속. EU는 피부 접촉 제품 용출 기준 운영 |

## 7. 인증별 보증 내용

| 인증 | 가점 | 내용 |
|---|---|---|
| OEKO-TEX Class I | +10 | 국제 섬유 유해물질 인증의 영유아(36개월 이하) 등급. 4개 등급 중 가장 엄격 |
| GOTS | +7 | 국제 유기농 섬유 인증. 원료 재배부터 가공·염색까지 전 과정 심사 |
| KC 안전확인 | +7 | 지정 기관 시험 후 성적서를 신고하는 어린이제품 인증 |
| 위생용품 적합 | +7 | 위생용품 관리법 기준 충족 (기저귀 등) |
