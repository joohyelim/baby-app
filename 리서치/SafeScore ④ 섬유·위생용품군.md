# SafeScore ④ 섬유·위생용품군 (v1.0)

- 적용 규제: 어린이제품 안전특별법 + 위생용품 관리법
- 품목: 배냇저고리, 속싸개·손싸개, 가제 손수건, 침구, 기저귀
- 소속 타일: 입히기·재우기 / 위생·청소(기저귀)
- 원칙: 피부에 종일 닿는 것. 소재와 가공 잔류물 기준

## 1. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 가점은 인증 최대 +18, 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 또는 −15 항목 1개 이상이면 점수와 무관하게 최고 C+ |
| 의무 KC 미표시 | 어린이제품 KC 없으면 최고 C+ |
| 혼용률 미표기 | 소재 정보 없으면 최고 C |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 성분 0 + 착한 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| A 예외 | 순면 100% 단일 소재는 무인증도 A−까지 |
| 정보 없음 ≠ 안심 | 혼용률 미표기 제품은 소재 가점 불인정 |

## 2. 감점표

| 감점 | 성분·요소 |
|---|---|
| −25 | 폼알데하이드, 아조염료, 납·카드뮴, 형광증백제 |
| −15 | pH 부적합 (약산성~중성 이탈) |
| −7 | 혼용률 미표기 |

## 3. 가점표

| 가점 | 항목 |
|---|---|
| +10 | OEKO-TEX Class I, 순면 100% 단일 소재 |
| +7 | GOTS, KC 안전확인, 위생용품 적합 (기저귀) |
| +3 | 무형광·무염색 명시, 천연펄프 (기저귀) |

- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 4. 특칙

- 기저귀: 24시간 밀착 + 점막 인접이라 형광증백제 검출 시 등급 상한 C가 아닌 즉시 D
- 배냇저고리·속싸개: 신생아 직접 접촉이라 염색 제품은 무염색 대비 가점 없이 채점 (감점은 아님)
- 월령별 차등: 이 군은 미도입. KC 유해물질 기준 자체가 36개월 이하 단일 기준이고, 신생아기 무염색 선호는 가점 구조로 이미 반영. 월령별로 감점을 달리할 학술 근거 부족

## 5. 계산 예시

순면 100% 배냇저고리, KC 안전확인, 무형광 명시, OEKO-TEX 없음

- 감점: 없음
- 가점: 순면 100% +10, KC 안전확인 +7, 무형광 +3 = +20
- 점수: 70 + 20 = 90
- A 조건 충족 (감점 0, 착한 요소, 인증, 90점)
- 결론: A−~A 구간. 큐레이션 노출

## 6. 감점 성분별 위험 근거

| 성분·요소 | 이유 |
|---|---|
| 폼알데하이드 | 1군 발암물질. 새 옷의 접착제·수지 가공에서 잔류 |
| 아조염료 | 섬유 염색용. 일부가 몸에서 발암성 물질(아릴아민)로 분해 |
| 납·카드뮴 | 신경 발달 저해, 몸에 쌓이고 배출 안 됨. 스냅단추·프린트에서 검출 |
| 형광증백제 | 하얗게 보이게 하는 형광물질. 기저귀·가제에서 검출 이슈 반복 |
| pH 부적합 | 피부 접촉 섬유의 안전 기준(약산성~중성) 이탈. 피부 자극 |

## 7. 인증별 보증 내용

| 인증 | 가점 | 내용 |
|---|---|---|
| OEKO-TEX Class I | +10 | 국제 섬유 유해물질 인증의 영유아(36개월 이하) 등급. 4개 등급 중 가장 엄격 |
| GOTS | +7 | 국제 유기농 섬유 인증. 원료 재배부터 가공·염색까지 전 과정 심사 |
| KC 안전확인 | +7 | 지정 기관 시험 후 성적서를 신고하는 어린이제품 인증 |
| 위생용품 적합 | +7 | 위생용품 관리법 기준 충족 (기저귀 등) |
