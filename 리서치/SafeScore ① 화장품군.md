# SafeScore ① 화장품군 (v1.0)

- 적용 규제: 화장품법 (전성분 공개 의무)
- 품목: 워시, 샴푸, 크림, 로션, 오일, 선케어, 수딩젤, 태열·발진크림, 물티슈, 구강티슈, 밤·립밤, 에센스/세럼, 미스트/토너 (뒤 3종은 맘가이드 유아 스킨케어 세분류 참고해 추가. 0~2세 실사용 빈도 확인 후 1차 포함 여부 결정 ⏳)
- 소속 타일: 씻기기 / 케어 / 위생·청소
- 벤치마크: 맘가이드 (라이브 확인본 2026-07-01)

## 1. 맘가이드에서 가져온 것과 다르게 가는 것

가져오는 것

- 등급(성분 자동판정)과 인증 배지의 분리 노출. 맘가이드의 초록 등급과 파란 클린마크 분리 구조
- 등급 서사: 정부 기준에 따라 제조되어 적정량 사용 시 안전하지만, 피부 장벽이 약한 아기 기준으로 한 번 더 엄격하게 분류
- 워시오프와 리브온의 구분 논리. 단 계산식에 배수를 두지 않고 특칙으로만 반영 (식품 SafeScore v3와 같은 단일 계산식 유지)
- 주의 성분 아이콘 체크리스트 노출 방식 (2026-08 상세 화면 재확인). 맘가이드는 제품 상세에 가습기 살균제 계열·향료·색소·4급 암모늄·SLS/SLES 함유 여부를 아이콘 세트로 표시하고, 미함유는 회색 처리. 우리 감점표 성분과 정확히 겹치는 세트라 베베덱스 상세 화면도 감점 성분 아이콘 온오프 방식 채택 (감점 근거를 한눈에 보여주는 UX)
- 참고만 하고 도입 안 하는 것: 어워드·수상 이력 표시(자체 어워드 없음), 복수 카테고리 랭킹, 구매 연결(1차 스코프 외), 크라우드소싱 수정 요청 버튼(정보 신뢰 관리 어려움, 2차 검토)

다르게 가는 것

- 데이터 원칙: 구조는 맘가이드에서 배우고 데이터는 식약처에서 가져옴. 맘가이드가 자체 구축한 성분별 판정 데이터(유해 성분 약 2,000종)는 그들의 자산이라 옮겨 쓰면 저작권·이용약관 침해 소지. 베베덱스 감점 목록은 식약처 공식 고시(영유아 사용금지·사용제한·주의 성분)를 근거로 직접 구축. EWG·환경부 자료는 애매한 성분 판단 시 보조 참고만. ECHA(유럽화학물질청)는 EU 규제기관 공식 데이터라 보조 참고 1순위 (맘가이드도 상세 화면에 ECHA 피부·호흡기 위험 아이콘 사용. §3 보수 원칙의 EU 금지 성분 판단 원천이기도 함)
- 자체 심사 마크 없음. 공적 인증(KC, 의약외품 허가 등) 보유 여부만 배지로 표기

EWG 등급을 점수에 직접 반영하지 않는 이유

- 미국 비영리 환경단체의 자체 등급이지 규제기관 기준 아님. 근거 논문의 선별 기준이 불투명하고, 위험을 실제보다 높게 또는 낮게 매길 수 있다는 지적이 있음 (와이즐리 블로그 EWG 신뢰성 글 참고)
- 성분 자체 등급이라 제품 내 농도·배합을 반영 못 함. 같은 성분도 0.001%와 5%는 위험이 다른데 등급은 하나
- 데이터 가용성 문제: 연구 자료가 부족한 성분은 정보 부족 상태로 등급이 매겨져, 낮은 등급 숫자가 안전 입증이 아니라 미검증일 수 있음
- EWG 그린 등급 마케팅이 국내에서 안전 인증처럼 소비되는 것 자체가 오해. 인증이 아니라 참고 지표
- 베베덱스 처리: 감점·가점 어디에도 EWG 등급 미사용. 식약처 고시가 1차 기준, EWG는 고시에 없는 애매한 성분을 내부 검토할 때 보조 참고만. 제품 화면에 EWG 등급 표기도 하지 않음 (표기하는 순간 인증처럼 읽히는 문제)

## 2. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 감점 합계에 상한 없음, 가점은 인증 최대 +18, 무첨가 등 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 또는 −15 성분 1개 이상이면 점수와 무관하게 최고 C+ |
| 전성분 미공개 | 화장품법 의무 위반이라 최고 C+ |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 성분 0 + 무첨가 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| 정보 없음 ≠ 안심 | 전성분 미표기 제품은 무첨가 가점 불인정 |

## 3. 감점표

| 감점 | 성분 |
|---|---|
| −25 | CMIT/MIT, 파라벤류, 벤잘코늄클로라이드, 식약처 영유아 금지·주의 고시 성분 |
| −15 | 페녹시에탄올(⏳ −25 상향 논의 중), SLES/SLS, 세트리모늄브로마이드, 합성보존료, 릴리알(부틸페닐메틸프로피오날) |
| −7 | 합성향료, 인공색소 |

- 보수 원칙 (확정): 국내는 허용이라도 EU 등 주요 규제기관이 사용 금지한 성분은 −15 이상 감점. 아기 안전은 가장 엄격한 기준을 따르는 것이 베베덱스의 존재 이유. 릴리알이 첫 적용 사례 (EU 2022년 사용 금지·생식독성 우려, 국내는 표시 관리)

## 4. 가점표

| 가점 | 항목 |
|---|---|
| +10 | 의약외품 허가 |
| +7 | 위생용품 적합 (물티슈) |
| +5 | 저자극 시험 성적서, 기능성 화장품 심사 (선케어) |
| +3 | 무첨가 명시 (무파라벤·무향·무색소), 전성분 자발 공개 상세도 |
| +2 | 신생아 사용 가능 표기 |

- 인증 가점(+10/+7/+5) 합산 최대 +18, 무첨가 등 착한 요소(+3/+2) 합산 최대 +12
- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 5. 특칙 (잔류 방식 차이는 여기서만 반영)

- 물티슈·구강티슈: −25 또는 −15 성분 1개면 등급 상한 C+ (하루 수십 회 상시 접촉, 구강티슈는 입 안 접촉)
- 리브온 제품(크림, 로션, 오일, 선케어, 수딩젤, 태열·발진크림): 바르고 씻지 않아 성분이 피부에 남으므로 −7 성분(합성향료·인공색소) 2개 이상이면 등급 상한 B
- 워시오프 제품(워시, 샴푸): 씻어내서 잔류 시간이 짧아 추가 제한 없음

## 6. 월령별 민감 성분 규칙

- 작동 방식: 점수·등급은 월령과 무관하게 고정 (계산식은 하나). 월령 축은 아기 월령(마중물 단계) 기준의 노출 제한과 경고 배지로만 작동. 식품 SafeScore v3의 연령적합성 마스터와 같은 축
- 근거가 확실한 항목만 도입. 근거 약한 항목은 추가하지 않음

| 월령 | 대상 | 규칙 | 근거 |
|---|---|---|---|
| 0~5개월 | 자외선차단제 전체 | 해당 월령에 비노출. 차광·의류·모자 우선 안내 | 미국 FDA·미국소아과학회(AAP): 6개월 미만은 차단제 사용 자체 비권장 |
| 0~5개월 | 향료 함유 제품 | ⚠️ 경고 배지 | 신생아기 피부 장벽 미성숙, 접촉성 자극 위험 최대 시기 |
| 0~36개월 | 살리실릭애씨드(BHA) | 검출 시 −25 (씻어내는 샴푸는 제외) | 식약처 고시: 만 3세 이하 사용 금지 성분 |
| 0~36개월 | IPBC(아이오도프로피닐부틸카바메이트) | 검출 시 −25 | 식약처 고시: 만 3세 이하 사용 제한 성분 |
| 0~24개월 | 멘톨·캄파(장뇌) 함유 | ⚠️ 경고 배지 | 영아 호흡 억제·경련 사례 보고 (특히 캄파) |

- 살리실릭애씨드·IPBC는 감점표의 식약처 고시 성분 −25 행의 구체 예시. 베베덱스 대상이 0~2세라 사실상 상시 적용
- 월령별 금지·제한 성분의 전체 목록 원천: [화장품 안전기준 등에 관한 규정 (식약처 고시)](https://www.law.go.kr/%ED%96%89%EC%A0%95%EA%B7%9C%EC%B9%99/%ED%99%94%EC%9E%A5%ED%92%88%20%EC%95%88%EC%A0%84%EA%B8%B0%EC%A4%80%20%EB%93%B1%EC%97%90%20%EA%B4%80%ED%95%9C%20%EA%B7%9C%EC%A0%95) — 별표 1 사용할 수 없는 원료, 별표 2 사용상 제한 원료 (영유아·어린이 제한 포함). 고시 개정 시 목록 갱신

## 6-1. 알레르기 유발 착향제 25종 ⚠️ 표시 규칙 (확정)

- 작동 방식: 감점 없음. 제품 상세에 검출 성분명 표기 + 향료 알레르기 주의 ⚠️ 배지 + 안내 문구 (예: 아기 피부에 알레르기 반응을 일으킬 수 있는 향료 성분이 들어 있어요)
- 근거: 식약처 고시. 씻어내는 제품 0.01% 초과, 씻어내지 않는 제품 0.001% 초과 시 전성분에 개별 성분명 표시 의무. 표시 의무 성분이라 제품 전성분에서 그대로 확인 가능
- 감점 미부여 이유: 법이 금지가 아닌 표시로 관리하는 성분. 점수는 법정 금지·제한 성분 중심으로 유지하고, 알레르기는 아기마다 달라 정보 제공이 목적

## 7. 계산 예시

무향·무파라벤 로션, 페녹시에탄올 함유, 저자극 성적서 보유

- 감점: 페녹시에탄올 −15
- 가점: 저자극 성적서 +5, 무첨가 명시 +3 = +8
- 점수: 70 − 15 + 8 = 63
- 등급 제한: −15 성분 검출이라 최고 C+이나 63점은 이미 D 구간
- 결론: D. 1차 비노출

## 8. 감점 성분별 위험 근거

| 성분 | 이유 |
|---|---|
| CMIT/MIT | 가습기 살균제 사태의 원인 물질 계열. 호흡기·피부 손상, 물티슈와 씻지 않는 화장품에 사용 금지 |
| 파라벤류 | 보존제. 호르몬(내분비계) 교란 의심, 영유아는 피부 투과율이 높아 더 취약 |
| 벤잘코늄클로라이드 | 살균 보존제. 피부·호흡기 자극, 가습기 살균제 성분 중 하나 |
| 식약처 영유아 금지·주의 고시 성분 | 식약처가 영유아 화장품에 금지·제한한 공식 목록. 목록 자체가 근거 |
| 페녹시에탄올 | 파라벤 대체 보존제. 식약처가 농도 1% 제한으로 허용 중이라 금지급 아님. 매일 온몸에 쓰는 영유아 제품에선 논쟁 |
| SLES / SLS | 세정력이 강한 합성 계면활성제. 아기 피부 장벽에 자극·건조 유발 |
| 세트리모늄브로마이드 | 4급 암모늄 계열 보존·컨디셔닝제. 두피·피부 자극 |
| 합성보존료 | 화학 보존제 총칭. 접촉성 피부염의 흔한 원인 |
| 합성향료·인공색소 | 알레르기·자극 유발 가능. 향료는 세부 성분 비공개(영업비밀)라 검증 불가한 점도 문제 |

## 11. 논의 필요 사항 ⏳

### 11-1. 전성분 분석·성분별 등급화 도입 여부

화해처럼 제품 전성분을 읽어 성분마다 등급을 매기는 방식의 도입 여부. 현실 진단은 아래와 같음

| 단계 | 난이도 | 이유 |
|---|---|---|
| 전성분 목록 확보 | 쉬움 | 화장품법상 전성분 표시 의무. 제조사·판매 페이지에 공개된 정보 |
| 감점표 성분 매칭 | 중간 | 자동화 가능. 단 같은 성분의 표기가 제각각(페녹시에탄올/Phenoxyethanol/페녹시에타놀 등)이라 성분명 정규화 사전 필요 |
| 전성분 개별 등급화 | 어려움 | 감점표 밖 수천 종 성분에 평가 기준 없음. EWG 등급 데이터도 저작권상 그대로 사용 불가. 자체 성분 DB 구축은 장기 과제 |

- 핵심 쟁점: 감점표에 없는 성분의 처리 방식. 목록에 없음을 안전으로 표시하면 위음성 위험, 미평가로 표시하면 화면이 물음표투성이가 되는 문제
- 제안: 1차는 전성분 스캔 + 감점표 매칭까지만 (A·B만 노출하는 구조라 걸러내기는 이걸로 충분). 성분별 등급 표기는 2차 이후 자체 성분 DB를 늘려가며 단계 도입
- 실데이터 채점을 화장품군에도 돌려 감점표에 빠진 성분을 찾는 작업 필요 (식품 실데이터 40종 튜닝과 동일 방식)

### 11-2. 해외 금지 성분 보수 원칙의 적용 범위

- 릴리알은 −15 감점으로 확정 (§3 보수 원칙. 안전을 위해 가장 엄격한 규제 기준 적용)
- 남은 논의: EU 금지 성분을 릴리알 외에 얼마나 더 조사·반영할지. EU 화장품 규정(EC 1223/2009) 부속서 II 금지 목록과 국내 고시의 차이 성분을 전수 비교하는 작업 필요 여부
- 형평 기준: EU 금지면 −15, EU 제한이고 국내 허용이면 ⚠️ 같은 단계 규칙을 만들지
