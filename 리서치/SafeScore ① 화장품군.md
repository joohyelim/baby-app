# SafeScore ① 화장품군 (v1.0)

- 적용 규제: 화장품법 (전성분 공개 의무)
- 품목: 워시, 샴푸, 크림, 로션, 오일, 선케어, 수딩젤, 태열·발진크림, 물티슈, 구강티슈, 밤·립밤, 에센스/세럼, 미스트/토너 (뒤 3종은 맘가이드 유아 스킨케어 세분류 참고해 추가. 0~2세 실사용 빈도 확인 후 1차 포함 여부 결정 ⏳)
- 소속 타일: 씻기기 / 케어 / 위생·청소
- 벤치마크: 맘가이드 (라이브 확인본 2026-07-01)

## 1. 맘가이드에서 가져온 것과 다르게 가는 것

가져오는 것

- 등급(성분 자동판정)과 인증 배지의 분리 노출. 맘가이드의 초록 등급과 파란 클린마크 분리 구조
- 등급 서사: 정부 기준에 따라 제조되어 적정량 사용 시 안전하지만, 피부 장벽이 약한 아기 기준으로 한 번 더 엄격하게 분류
- 워시오프와 리브온의 구분 논리. 단 계산식에 배수를 두지 않고 특칙으로만 반영 (식품 SafeScore v3와 같은 단일 계산식 유지)
- 주의 성분 아이콘 체크리스트 노출 방식 (2026-08 상세 화면 재확인). 맘가이드는 제품 상세에 가습기 살균제 계열·향료·색소·4급 암모늄·SLS/SLES 함유 여부를 아이콘 세트로 표시하고, 미함유는 회색 처리. 우리 감점표 성분과 정확히 겹치는 세트라 베베덱스 상세 화면도 감점 성분 아이콘 온오프 방식 채택 (감점 근거를 한눈에 보여주는 UX)
- 참고만 하고 도입 안 하는 것: 어워드·수상 이력 표시(자체 어워드 없음), 복수 카테고리 랭킹, 구매 연결(1차 스코프 외), 크라우드소싱 수정 요청 버튼(정보 신뢰 관리 어려움, 2차 검토)
- 클린마크 발급 기준 (2026-08 앱 확인, 참고만): ① 법적 기준 검토(유관 법령 부합) ② 주의 성분 함유 여부 검토(성분·제품 안전성 자료 제출) ③ 투명성 검토(표시·광고 및 라벨링 기준 준수)의 3단계. 특이점은 소명자료 구조 — 주의 성분을 함유해도 업체가 소명자료를 제출해 검토 완료되면 마크 부여 + 해당 성분을 주의 성분에서 제외하고, 기준 충족한 B등급 제품은 A등급으로 상향(마크 발급 기간 한정). 마크 미발급 제품은 업체 표기 전성분만으로 등급 부여. 베베덱스는 자체 심사 마크가 없어 소명자료 예외·등급 상향 구조 비도입 (감점표 성분은 함유 사실만으로 감점, 예외 없음 — 심사 인력 없이 일관성을 지키는 선택)

다르게 가는 것

- 데이터 원칙: 구조는 맘가이드에서 배우고 데이터는 식약처에서 가져옴. 맘가이드가 자체 구축한 성분별 판정 데이터(유해 성분 약 2,000종)는 그들의 자산이라 옮겨 쓰면 저작권·이용약관 침해 소지. 베베덱스 감점 목록은 식약처 공식 고시(영유아 사용금지·사용제한·주의 성분)를 근거로 직접 구축. EWG·환경부 자료는 애매한 성분 판단 시 보조 참고만. ECHA(유럽화학물질청)는 EU 규제기관 공식 데이터라 보조 참고 1순위 (맘가이드도 상세 화면에 ECHA 피부·호흡기 위험 아이콘 사용. §3 보수 원칙의 EU 금지 성분 판단 원천이기도 함)
- 자체 심사 마크 없음. 공적 인증(KC, 의약외품 허가 등) 보유 여부만 배지로 표기

EWG 등급 처리 방식: 레드 등급만 감점 반영, 그린 등급 미사용 (2026-08 확정)

- 맘가이드 가이드북(앱 내 성분 판단 기준 공개, 2026-08 확인)에서 성분 등급의 원천이 EWG(Skin Deep·Guide to Healthy Cleaning·Food Scores)임을 공식 확인. 즉 맘가이드 등급 = EWG 등급 + 다국 주의성분 리스트 조합. 베베덱스는 식약처 고시 1차 + 공적 기관 보조로 가는 것이 등급 체계 차원의 차별화 지점
- 미국 비영리 환경단체의 자체 등급이지 규제기관 기준 아님. 근거 논문의 선별 기준이 불투명하고, 위험을 실제보다 높게 또는 낮게 매길 수 있다는 지적이 있음 (와이즐리 블로그 EWG 신뢰성 글 참고)
- 성분 자체 등급이라 제품 내 농도·배합을 반영 못 함. 같은 성분도 0.001%와 5%는 위험이 다른데 등급은 하나
- 데이터 가용성 문제: 연구 자료가 부족한 성분은 정보 부족 상태로 등급이 매겨져, 낮은 등급 숫자가 안전 입증이 아니라 미검증일 수 있음
- EWG 그린 등급 마케팅이 국내에서 안전 인증처럼 소비되는 것 자체가 오해. 인증이 아니라 참고 지표
- 베베덱스 처리 (2026-08 수정 확정): 등급 전면 반영은 안 하되, EWG가 유해성 기준이라는 특성을 살려 레드 등급(7~10점, 높은 위험)만 감점 근거로 반영 (§3의 −7 행). 그린 등급(1~2점)은 가점·안전 표시 어디에도 미사용 (낮은 점수가 안전 입증이 아니라 미검증일 수 있는 문제라 위험 경고 방향만 신뢰). 제품 화면에 EWG 등급 숫자 자체는 표기하지 않음 (표기하는 순간 인증처럼 읽히는 문제)

보조 참고 원천 우선순위 (맘가이드 가이드북 원천 스택 참고, 공적 기관만 선별)

| 순위 | 원천 | 용도 |
|---|---|---|
| 1 | ECHA (CLP 위험 분류, Perfume Allergies List, C&L Inventory) | EU 규제기관 공식 데이터. 보수 원칙의 EU 금지·제한 판단, 착향제 알레르기 목록 |
| 2 | EU SCCS (소비자안전과학위원회) | EU 화장품 성분 규제의 과학적 근거 의견서. 금지·제한 결정의 배경 확인 |
| 3 | 식약처 독성정보 제공시스템 (Tox-Info) | 국내 공식 독성 데이터. 애매 성분 내부 검토 |
| 4 | IARC·EPA·EU CMR 리스트 (발암성·변이원성·생식독성·내분비계교란) | 고독성 물질 확인. −25급 판단 보조 |
| 5 | 미국 CIR (화장품원료검토위원회) Safety Assessment | 업계 자율 기구이나 성분별 안전성 평가 보고서가 상세. 참고용 |
| 6 | 국립환경과학원 (화학물질의 분류 및 표시 등에 관한 규정 유해화학물질 리스트) | 국내 공식 유해화학물질 분류. 맘가이드 유해성분 판단 원천 중 하나 |
| 7 | 일본 후생노동성 화장품기준 (2026-08 추가) | 보존제·자외선차단제·타르색소를 포지티브 리스트로 관리하는 세계 최엄격 축. 일본 리스트 미등재 보존제는 보수 판단의 강한 신호 |

- 맘가이드 자체 주의성분 DB(약 2,000종)가 공적 기관 원천의 조합임을 앱 내에서 공식 확인 (2026-08, 아이폰 앱 직접 확인)
  - 가이드북 공통 탭 성분 판단 기준: 맘가이드는 EWG 등급뿐만 아니라 10가지 이상의 국내외 화학물질 유해성 데이터를 통해 성분 유해성을 판단한다고 명시. 원천 목록 = EWG(등급) / CIR Safety Assessment·국내외 저널·식약처 독성정보 제공시스템(자체 주의성분) / EPA Safer Chemical Ingredients List / 캐나다 환경부 DSL / 미국·캐나다·유럽·국제향료협회 금지 목록(해외 금지 성분) / IARC·EPA·EU·환경부·고용노동부 CMR·내분비계교란 리스트(고독성) / EU SCCS·ECHA(사용방법별 체크 성분) / 국립환경과학원(유해성분) / 한국산업환경기술원 환경표지(친환경 인증)
  - 가이드북 리빙·스킨케어 탭 클린마크 항목: 맘가이드 클린 제품은 국내외 공신력 있는 연구기관 및 국가기관의 성분 분석 데이터를 기반으로 검토한다고 명시
- 결론: 맘가이드의 판단도 결국 위 공적 원천의 조합. 원천 자체는 전부 공개 데이터라 베베덱스가 같은 원천을 직접 참조하는 데 저작권 문제 없음. 판단 결과물(맘가이드 자체 주의성분 목록·등급)만 그들 자산이라 미사용. 위 우선순위 표는 이 원천 스택에서 공적 기관만 선별한 것

## 2. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 감점 합계에 상한 없음, 가점은 인증 최대 +18, 무첨가 등 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 또는 −15 성분 1개 이상이면 점수와 무관하게 최고 C+ |
| 전성분 미공개 | 화장품법 의무 위반이라 최고 C+ |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| A 조건 | 감점 성분 0 + 무첨가 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| 정보 없음 ≠ 안심 | 전성분 미표기 제품은 무첨가 가점 불인정 |

## 3. 감점표

| 감점 | 성분 |
|---|---|
| −25 | CMIT/MIT, 파라벤류, 벤잘코늄클로라이드, 식약처 영유아 금지·주의 고시 성분 |
| −15 | 페녹시에탄올(⏳ −25 상향 논의 중), SLES/SLS, 세트리모늄브로마이드, 합성보존료, 릴리알(부틸페닐메틸프로피오날), 징크피리치온, HICC(리랄)·아트라놀·클로로아트라놀, 폼알데하이드 방출 보존제(DMDM하이단토인·쿼터늄-15·이미다졸리디닐우레아·디아졸리디닐우레아), 4-MBC(4-메틸벤질리덴캠퍼), 붕산·붕산염류(보레이트) |
| −7 | 합성향료, 인공색소, EWG 레드 등급(7~10) 성분, 트리클로산 |

- 보수 원칙 (확정): 국내는 허용이라도 EU 등 주요 규제기관이 사용 금지한 성분은 −15 이상 감점. 아기 안전은 가장 엄격한 기준을 따르는 것이 베베덱스의 존재 이유. 적용 사례: 릴리알 (EU 2022 금지·생식독성), 징크피리치온 (EU 2022 금지·생식독성 1B, 국내는 샴푸 등 사용제한으로 허용), HICC·아트라놀·클로로아트라놀 (EU 2021 완전 금지, 접촉 알레르기 최다 유발 향료), 4-MBC (EU 2025-05 금지·내분비계 교란, Regulation 2024/996), 붕산·붕산염류 (캐나다 Hotlist 3세 미만 금지·발달독성, 캘리포니아 AB 496으로 2027 전면 금지 예정. 국내 고시상 영유아 특별 조항 유무 재확인 ⏳)
- EWG 레드 등급 −7 (확정): EWG는 유해성 기준이므로 위험 경고 방향만 반영. 식약처 고시·EU 금지 목록에 이미 있는 성분은 해당 행의 감점을 적용하고, 어디에도 없는데 EWG 7~10점인 성분만 이 행으로 −7. 단독으로는 등급 상한(최고 C+) 미적용
- 폼알데하이드 방출 보존제: 보존 과정에서 폼알데하이드를 서서히 방출하는 계열. 쿼터늄-15는 EU 금지, 나머지도 EU 표기 의무·캐나다 Hotlist 제한 대상. 국내는 허용이라 보수 원칙 −15
- 트리클로산 −7 (확정, 2026-08): EU·국내 모두 제한(0.3%)이라 금지 갭은 아니나, SCCS가 내분비계 교란 의심 의견을 낸 성분. 금지가 아닌 제한이라 −15가 아닌 −7로 보수 감점

## 4. 가점표

| 가점 | 항목 |
|---|---|
| +10 | 의약외품 허가 |
| +7 | 위생용품 적합 (물티슈) |
| +5 | 저자극 시험 성적서, 기능성 화장품 심사 (선케어) |
| +3 | 무첨가 명시 (무파라벤·무향·무색소), 전성분 자발 공개 상세도 |
| +2 | 신생아 사용 가능 표기 |

- 인증 가점(+10/+7/+5) 합산 최대 +18, 무첨가 등 착한 요소(+3/+2) 합산 최대 +12
- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 5. 특칙 (잔류 방식 차이는 여기서만 반영)

- 물티슈·구강티슈: −25 또는 −15 성분 1개면 등급 상한 C+ (하루 수십 회 상시 접촉, 구강티슈는 입 안 접촉)
- 리브온 제품(크림, 로션, 오일, 선케어, 수딩젤, 태열·발진크림): 바르고 씻지 않아 성분이 피부에 남으므로 −7 성분(합성향료·인공색소) 2개 이상이면 등급 상한 B
- 워시오프 제품(워시, 샴푸): 씻어내서 잔류 시간이 짧아 추가 제한 없음

## 6. 월령별 민감 성분 규칙

- 작동 방식: 점수·등급은 월령과 무관하게 고정 (계산식은 하나). 월령 축은 아기 월령(마중물 단계) 기준의 노출 제한과 경고 배지로만 작동. 식품 SafeScore v3의 연령적합성 마스터와 같은 축
- 근거가 확실한 항목만 도입. 근거 약한 항목은 추가하지 않음

| 월령 | 대상 | 규칙 | 근거 |
|---|---|---|---|
| 0~5개월 | 자외선차단제 전체 | 해당 월령에 비노출. 차광·의류·모자 우선 안내 | 미국 FDA·미국소아과학회(AAP): 6개월 미만은 차단제 사용 자체 비권장 |
| 0~5개월 | 향료 함유 제품 | ⚠️ 경고 배지 | 신생아기 피부 장벽 미성숙, 접촉성 자극 위험 최대 시기 |
| 0~36개월 | 살리실릭애씨드(BHA) | 검출 시 −25 (씻어내는 샴푸는 제외) | 식약처 고시: 만 3세 이하 사용 금지 성분 |
| 0~36개월 | IPBC(아이오도프로피닐부틸카바메이트) | 검출 시 −25 | 식약처 고시: 만 3세 이하 사용 제한 성분 |
| 0~24개월 | 멘톨·캄파(장뇌) 함유 | ⚠️ 경고 배지 | 영아 호흡 억제·경련 사례 보고 (특히 캄파) |

- 살리실릭애씨드·IPBC는 감점표의 식약처 고시 성분 −25 행의 구체 예시. 베베덱스 대상이 0~2세라 사실상 상시 적용
- 월령별 금지·제한 성분의 전체 목록 원천: [화장품 안전기준 등에 관한 규정 (식약처 고시)](https://www.law.go.kr/%ED%96%89%EC%A0%95%EA%B7%9C%EC%B9%99/%ED%99%94%EC%9E%A5%ED%92%88%20%EC%95%88%EC%A0%84%EA%B8%B0%EC%A4%80%20%EB%93%B1%EC%97%90%20%EA%B4%80%ED%95%9C%20%EA%B7%9C%EC%A0%95) — 별표 1 사용할 수 없는 원료, 별표 2 사용상 제한 원료 (영유아·어린이 제한 포함). 고시 개정 시 목록 갱신

## 6-1. 알레르기 유발 착향제 25종 ⚠️ 표시 규칙 (확정)

- 작동 방식: 감점 없음. 제품 상세에 검출 성분명 표기 + 향료 알레르기 주의 ⚠️ 배지 + 안내 문구 (예: 아기 피부에 알레르기 반응을 일으킬 수 있는 향료 성분이 들어 있어요)
- 근거: 식약처 고시. 씻어내는 제품 0.01% 초과, 씻어내지 않는 제품 0.001% 초과 시 전성분에 개별 성분명 표시 의무. 표시 의무 성분이라 제품 전성분에서 그대로 확인 가능
- 감점 미부여 이유: 법이 금지가 아닌 표시로 관리하는 성분. 점수는 법정 금지·제한 성분 중심으로 유지하고, 알레르기는 아기마다 달라 정보 제공이 목적

## 6-2. 흡입 위험 ⚠️ 표시 규칙 (확정, 2026-08)

- 작동 방식: 감점 없음. 해당 형태 제품에 ⚠️ 배지 + 안내 문구
- 대상 2건
  - 탈크 함유 분말형 제품 (베이비파우더 등): 비산 분말 흡입 위험. 캐나다 Hotlist 유아용 제품 제한, 미국 MoCRA 석면 시험 의무화. 안내 문구 예: 가루가 날리는 제품이에요. 아기 얼굴 근처 사용은 피해 주세요
  - 나노 이산화타이타늄 함유 스프레이형 제품 (스프레이 선케어 등): EU가 흡입 노출 형태(스프레이·분말)에 사용 금지. 크림·로션형은 해당 없음
- 감점 미부여 이유: 성분 자체가 아닌 제형(노출 형태)의 문제. 같은 성분도 크림형은 안전해 성분 감점으로 다루면 과잉 처벌. ②군의 노출 경로 2분법과 같은 논리

무향·무파라벤 로션, 페녹시에탄올 함유, 저자극 성적서 보유

- 감점: 페녹시에탄올 −15
- 가점: 저자극 성적서 +5, 무첨가 명시 +3 = +8
- 점수: 70 − 15 + 8 = 63
- 등급 제한: −15 성분 검출이라 최고 C+이나 63점은 이미 D 구간
- 결론: D. 1차 비노출

## 11. 논의 필요 사항 ⏳

### 11-1. 전성분 분석·성분별 등급화 도입 여부

화해처럼 제품 전성분을 읽어 성분마다 등급을 매기는 방식의 도입 여부. 현실 진단은 아래와 같음

| 단계 | 난이도 | 이유 |
|---|---|---|
| 전성분 목록 확보 | 쉬움 | 화장품법상 전성분 표시 의무. 제조사·판매 페이지에 공개된 정보 |
| 감점표 성분 매칭 | 중간 | 자동화 가능. 단 같은 성분의 표기가 제각각(페녹시에탄올/Phenoxyethanol/페녹시에타놀 등)이라 성분명 정규화 사전 필요 |
| 전성분 개별 등급화 | 어려움 | 감점표 밖 수천 종 성분에 평가 기준 없음. EWG 등급 데이터도 저작권상 그대로 사용 불가. 자체 성분 DB 구축은 장기 과제 |

- 핵심 쟁점: 감점표에 없는 성분의 처리 방식. 목록에 없음을 안전으로 표시하면 위음성 위험, 미평가로 표시하면 화면이 물음표투성이가 되는 문제
- 제안: 1차는 전성분 스캔 + 감점표 매칭까지만 (A·B만 노출하는 구조라 걸러내기는 이걸로 충분). 성분별 등급 표기는 2차 이후 자체 성분 DB를 늘려가며 단계 도입
- 실데이터 채점을 화장품군에도 돌려 감점표에 빠진 성분을 찾는 작업 필요 (식품 실데이터 40종 튜닝과 동일 방식)

### 11-2. 해외 금지 성분 보수 원칙의 적용 범위

전수 비교 조사 완료 (2026-08. EU·캐나다·미국 연방·미국 주·일본 4개 축 확인)

- 적용 사례 확정 5건: 릴리알·징크피리치온·HICC(리랄)·아트라놀·클로로아트라놀·4-MBC·붕산류 −15 (§3)
- 축별 조사 결론
  - EU (EC 1223/2009 부속서 II·III + Omnibus 개정 시리즈): 최근 금지분은 대부분 국내 고시도 동조. 잔여 갭은 4-MBC(반영 완료)와 아래 ⏳ 3건 수준
  - 캐나다 (Hotlist): 붕산류 3세 미만 금지가 최대 수확 (반영 완료). 탈크 유아용 제한은 ⏳
  - 미국 연방 (FDA 21 CFR 700): 금지 목록이 12종 내외로 짧고 국내와 사실상 일치. 추가 성분 없음 확정. MoCRA 탈크 석면 시험 의무만 탈크 논의에 참고
  - 미국 주 (캘리포니아 AB 496, 2027 발효): 붕산·붕산염 16종 포함. 붕산류 −15의 보강 근거로 사용
  - 일본 (후생노동성 화장품기준): 배합금지 네거티브 리스트에 더해 보존제·자외선차단제·타르색소는 포지티브 리스트(등재 성분만 허용)로 관리하는 이중 체계. 폼알데하이드는 전면 배합 금지. 신규 감점 성분 발굴보다는 기존 −15(폼알데하이드 방출 보존제)의 근거 보강과 보조 판단 원천(§1 표 7순위)으로 활용. 의약외품 유사 제도인 의약부외품은 허가제라 국내 기능성 신고제보다 엄격한 점도 참고
- 잔여 3건 처리 확정 (한솔 결정, 2026-08)
  - 트리클로산: 제한 성분이라 보수적으로 −7 감점 (§3)
  - 탈크 (분말형 제품): 감점 없이 ⚠️ 주의 표기만 (§6-2)
  - 나노 이산화타이타늄 (스프레이형): 감점 없이 ⚠️ 주의 표기 (§6-2)
- 형평 기준 (계속 논의): 해외 금지 = −15, 해외 제한 + 국내 허용 = ⚠️ 또는 −7 같은 단계 규칙 명문화 여부
- 해외 인증 검토 결과: 가점에 추가할 만한 해외 공적 인증은 없음. EWG Verified는 민간 마크라 미채택, EU CPNP 등록은 유통 요건이지 안전 인증이 아님. 가점표 변경 없음
