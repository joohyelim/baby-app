## 1. 홈 타일 확정안 (부모 장면 기준)

| 타일 | 품목 | 비고 |
|---|---|---|
| 먹이기 | 식품 전체 | 식품 SafeScore v3 적용 |
| 젖병·식기 | 젖병, 젖병솔, 빨대컵, 그릇·식판, 스푼, 젖병세정제, 소독기 | |
| 씻기기 | 워시, 샴푸, 아기욕조, 치약, 구강티슈 | |
| 케어 (구 발라주기) | 크림, 로션, 오일, 선케어, 수딩젤, 태열·발진크림 + 체온계, 콧물흡입기 | ⏳ 논의 필요 |
| 위생·청소 | 기저귀, 물티슈, 세탁세제, 섬유유연제, 클리너 | |
| 입히기·재우기 | 배냇저고리, 속싸개, 가제, 침구 + 습도계 | ⏳ 논의 필요 |
| 놀이·배움 (구 놀아주기) | 책, 장난감 일체, 치발기, 모빌 | 확정 |

아플 때 타일 해체 내역

- 체온계, 콧물흡입기 → 케어 (아기 몸에 대는 케어 용품이라는 논리. 타일 이름을 발라주기에서 케어로 확장)
- 습도계 → 입히기·재우기 (아기 방 환경 관리)
- ⏳ 논의 필요: 케어 확장과 습도계 행선지는 목요일 동업자 논의 안건. 소독기·욕조는 기존대로 젖병·식기, 씻기기 유지

## 2. 판별군 6개 (채점 단위, 내부용)

타일과 무관하게 제품에 적용되는 법·규제 체계로 채점. 유저에게 비노출

| 판별군 | 적용 규제 | 문서 |
|---|---|---|
| ① 화장품군 | 화장품법 | 스코어링_①화장품군.md |
| ② 구강·식기군 | 식품위생법 기구·용기 | 스코어링_②구강식기군.md |
| ③ 생활화학군 | 화학제품안전법 | 스코어링_③생활화학군.md |
| ④ 섬유·위생용품군 | 어린이제품법 + 위생용품법 | 스코어링_④섬유위생용품군.md |
| ⑤ 완구·교구군 | 어린이제품 안전특별법 | 스코어링_⑤완구교구군.md |
| ⑥ 기구군 | 어린이제품법 + 전기용품법 | 스코어링_⑥기구군.md |

각 문서는 자기완결 구성 (공통 규칙 포함, 그 문서만 읽어도 채점 가능)

제조국·원산지 처리 원칙 (전 판별군 공통)

- 제조국은 점수 미반영. 안전의 근거가 아니고(제조국과 무관하게 성분·인증·리콜로 판정 가능), 국내산 가점은 근거 제시 불가 + 표시광고법상 차별 소지
- 반영하는 것은 표기 여부: 제조국 미표기는 정보 부족 신호로 처리 (기구군 A 조건의 제조국 공개가 그 예)
- 소비자 노출: 국산/수입은 가치판단 없는 정보 필터와 상세 표시로만 제공
- 해외 직구품의 국내 의무 인증 미보유는 제조국 문제가 아니라 인증 미보유로 이미 등급 제한에 반영

월령 축 (식품 v3 연령적합성 마스터와 동일 원칙)

- 점수·등급은 월령과 무관하게 고정. 월령 축은 노출 제한과 경고 배지로만 작동 (계산식을 복잡하게 만들지 않음)
- 도입 판별군: ① 화장품군(선케어 6개월 미만 비노출, 식약처 만 3세 이하 금지 성분 등), ② 구강·식기군(불소 치약 월령 안내), ⑤ 완구·교구군(36개월 미만 경고 제품 제외, 자석·버튼전지 강등)
- 미도입 판별군: ③ ④ ⑥ (근거 부족 또는 규제 기준이 월령 단일. 각 문서에 판단 근거 기재)

## 3. 논의 필요 사항 전체 (목요일 안건)

1. 케어 타일 확장(체온계·콧물흡입기 흡수) 확정 여부
2. 습도계의 입히기·재우기 편입 확정 여부
3. 등급 세분화: ± 적용 범위(①~⑤ 전부 vs 일부), ⑥군 4단계 확정
4. 등급 컷 상향(B 80 / C 70) 확정
5. 페녹시에탄올 −15 유지 vs −25 상향 (①군 문서)
6. 리콜 시정 완료 이력 처리, N년 컷 (전 판별군 공통)
7. 판정 알고리즘: 70 기준선 방식 vs 가장 완벽한 제품 기준 감점 방식 (마스터기획서 결정항목 1)
8. 기준 공개 방식: 판별군 이름은 내부용으로 숨기고, 소비자에게는 제품 상세의 '이 제품의 평가 기준' + 기준 안내 페이지(쉬운 이름)로 고지. 공개 문구·페이지 구조 확정 필요
9. 미세플라스틱: PP 젖병 열탕 소독 시 방출 연구는 있으나 규제·건강 영향 근거 미확립이라 감점 미도입. 연구 축적 시 재검토 (②군 문서)
