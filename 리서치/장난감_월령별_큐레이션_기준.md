# 장난감 월령별 큐레이션 기준

> 대상: 0~24개월 상세 기준, 25~60개월 확장 기준  
> 목적: 월령별 핵심 발달·준비 신호와 구체적인 장난감 타입을 연결하고, 발달 철학 및 안전상 주의점을 태그로 제공한다.  
> 원문: [`월령별_발달단계_리서치.md`](./월령별_발달단계_리서치.md) §4에서 독립

## 1. 큐레이션 원칙

- `시작 월령`은 장난감이 **새로 유용해지기 시작하는 대략적인 노출 시점**이지 발달 판정 기준이 아니다. 실제 추천은 월령보다 `준비 신호`를 우선한다.
- CDC 발달 이정표는 해당 나이에 아이의 75% 이상이 보이는 행동이다. 장난감이 발달을 직접 만들거나 앞당긴다고 표현하지 않는다.
- 대근육 발달의 개인차는 특히 크다. WHO 정상 범위도 혼자 앉기 3.8~9.2개월, 네발기기 5.2~13.5개월, 혼자 걷기 8.2~17.6개월로 넓다.
- 한 장난감이 여러 월령에 적용될 때는 처음 유용해지는 행에 배치하고 `권장 범위`를 함께 표기한다. 이후에는 놀이 난이도만 확장한다.
- 한 시점의 핵심 픽은 3~5개로 제한하고, 아이가 직접 조작하는 개방형 장난감을 우선한다.
- 국민템이더라도 목록에서 숨기지 않는다. 기본 추천·준비 신호 확인·비권장을 구분하고 구체적인 사유를 태그로 표시한다.

## 2. 근거 프레임워크

| 프레임워크 | 적용 원칙 |
|---|---|
| **AAP Power of Play** | 단순하고 아이가 직접 조작하며 보호자와 상호작용할 수 있는 개방형 장난감 우선. 자동 빛·소리·화면은 보조로 제한 |
| **몬테소리** | 실제적이고 단순한 재료, 독립적 선택, 손 조작, 정돈된 소수의 장난감 |
| **피클러** | 아이가 스스로 시작하는 자유로운 움직임과 바닥 탐색 우선. 움직임을 인위적으로 앞당기거나 제한하지 않음 |
| **Dr. Toy** | 의학적 월령 기준이 아닌 놀이 가치 평가 프레임. 디자인·교육적 이점·독창성·놀이 가치·안전·재미 등을 보고, 앱에서는 활동성·창의성·교육성으로 요약 태깅 |

## 5. SafeScore 안전 평가 연계

> 출처: 원격 `master`의 `리서치/SafeScore ⑤ 완구·교구군.md` v1.0에서 장난감 관련 기준을 통합했다.  
> **분리 원칙:** SafeScore는 `제품 안전`을 평가하고, §4의 월령·발달·Dr. Toy 기준은 `큐레이션 적합성`을 평가한다. 안전 점수가 높다고 발달 가치가 높은 것은 아니며 그 반대도 아니다.

### 5.1 평가 대상과 다른 평가군으로 보내는 품목

| 구분 | 처리 |
|---|---|
| 일반 장난감·모빌·블록·역할놀이·탑승완구 | 완구 SafeScore 적용 |
| 치발기처럼 오래 입에 물고 빠는 제품 | 완구 점수가 아니라 구강·식기군의 용출 기준 적용 |
| 전자 장난감 | 완구 안전에 배터리함·음량·과자극 주의를 함께 표시 |
| 제조사 권장연령이 현재 월령보다 높은 제품 | 점수와 별개로 해당 월령 큐레이션에서 비노출 |

### 5.2 점수와 등급

```text
점수 = 70 - 감점 + 가점
최종 범위 = 0~100
```

### 11.5 검증 후 운영 판정

1. `연령 통과`, `발달 적합`, `SafeScore 발급 가능`을 서로 다른 상태로 저장한다.
2. KC 원문, SKU 소재·표면처리, 배터리함·자석·소부품 구조 중 필수정보가 빠지면 숫자 점수를 발급하지 않는다.
3. 월령표의 제품은 `후보`이며, 실제 앱 노출은 SKU 검증을 완료한 제품만 허용한다.
4. 이번 표본에서는 연령 게이트는 정상 작동했지만, SafeScore는 공개정보 부족을 처리하는 별도 상태가 없어 실제품에 바로 적용하기 어려웠다.
