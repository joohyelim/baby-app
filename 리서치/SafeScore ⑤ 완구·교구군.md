# SafeScore ⑤ 완구·교구군 (v1.0)

- 적용 규제: 어린이제품 안전특별법 (KC)
- 품목: 책(보드북·촉감책), 장난감 일체, 모빌
- 소속 타일: 놀이·배움
- 원칙: KC 인증 + 소재 + 발달 가치. 입에 무는 교구(치발기 등)는 ② 구강·식기군에서 채점

## 1. 점수 계산 (공통 규칙)

```
점수 = 70 − 감점 + 가점   → 0~100
```

- 가점은 인증 최대 +18, 착한 요소 최대 +12 (70+18+12=100 설계. 가점을 더 열면 점수가 100에 몰려 변별력 상실)

| 등급 | 점수 | 세분화 | 1차 노출 |
|---|---|---|---|
| A | 90~100 | A− / A / A+ | 노출 |
| B | 80~89 | B− / B / B+ | 노출 |
| C | 70~79 | C− / C / C+ | 비노출 |
| D | 50~69 | 없음 | 비노출 |
| E | 0~49 | 없음 | 비노출 |

등급 제한 규칙

| 규칙 | 내용 |
|---|---|
| 감점 성분 검출 | −25 항목 1개 이상이면 점수와 무관하게 최고 C+ |
| 의무 KC 미표시 | 어린이제품 KC 없으면 최고 C+ |
| 소재 미표기 | 최고 C |
| 진행 중 리콜 | 해당 모델은 즉시 강등 + 🔴 표시. 시정 완료 이력 처리는 논의 중 |
| 연령 부적합 | 작은 부품·자석이 대상 월령에 부적합하면 점수와 무관하게 강등 |
| A 조건 | 감점 성분 0 + 착한 요소 1개 이상 + 인증 1개 이상 + 90점 이상 |
| 정보 없음 ≠ 안심 | 소재 미표기 제품은 원목·수성도료 가점 불인정 |

## 2. 감점표

| 감점 | 성분·요소 |
|---|---|
| −25 | 납·카드뮴, 프탈레이트/PVC, 폼알데하이드 |
| −15 | 니트로사민·니트로사민 생성 물질 (고무·라텍스·탄성체 완구), PFAS 코팅 (발수·방오 가공 완구) |
| −7 | 유성도료·VOC, 향료 첨가 완구 (EU 완구 금지·제한 향료 해당 시) |

- 보수 원칙 (①②군과 공통, 2026-08 해외 갭 조사 반영): 국내 KC는 허용·미규정이라도 주요 규제기관이 금지한 물질은 감점
  - 니트로사민 −15: EU는 36개월 미만·입에 넣는 완구에 니트로사민 0.05mg/kg 기준(EN 71-12) 적용. 국내 KC에는 해당 기준 없음. 고무 치발기 겸용 완구·풍선류에 직결
  - PFAS −15: EU 신완구안전규정(Regulation 2025/2509, 2025 채택)이 PFAS 의도적 사용과 내분비계 교란 물질을 완구에서 금지 (단계 적용, 2030 완전 적용). 국내 미반영. 발수 코팅 헝겊책·놀이매트류 확인 대상
  - 향료 −7: EU가 완구 내 알레르기 유발 향료 다수를 금지·표시 의무화 (신규정에서 표시 기준 100→10mg/kg 강화). 국내 기준 없음. ①군 착향제 ⚠️와 연계
  - 미국 페인트 납 기준 참고: CPSIA 페인트 90ppm이 KC 100ppm(총납)보다 소폭 엄격하나 갭이 작아 별도 감점 없음. 근거 참고만
  - EU 신완구규정의 비스페놀 10종 금지는 ②군 비스페놀류 −25와 같은 방향. 플라스틱 완구 판단 시 동일 원칙 적용

## 3. 가점표

| 가점 | 항목 |
|---|---|
| +10 | KC 안전인증 |
| +7 | KC 안전확인, 유해물질 시험 통과 |
| +5 | KC 공급자적합성 |
| +3 | 원목·천연소재, 수성도료, 연령 적합 표기 |
| +3 | 발달 가치: 열린 장난감, 몬테소리 등 발달에 도움되는 유형 (별도 판별 기준 추후 문서화) |

- 인증 3단 구분 근거: +10 제3자가 직접 시험 / +7 기준 충족을 기관이 확인 / +5 자체 시험 또는 개별 성적서

## 4. 특칙

- 치발기: 입에 물고 빠는 시간이 길어 ② 구강·식기군 용출 기준으로 채점
- 보드북·촉감책: 36개월 미만 대상은 완구 KC 대상. 도서라는 이유로 KC 면제 아님 (놀이 기능 있으면 완구)
- 액체 완구 (비누방울액, 물감, 핑거페인트): EU는 36개월 미만용에 보존제 MIT·BIT·CMIT/MIT 제한 (EN 71 계열). 액체 완구는 보존제 성분 확인을 필수 체크 항목으로 (①③군 감점 성분과 동일 목록 적용)
- 발달 가치 가점은 안전 점수와 별개 축으로 노출하는 안도 검토 (안전 90 + 발달 배지 방식). ⏳ 논의 필요
- 교육 적합성 큐레이션 (예정): 몬테소리 등 교육 이론 기반의 소개·추천 축을 추후 추가. 안전 점수와 섞지 않고 별도 콘텐츠 축으로 설계 (예: 안전 A + 몬테소리 적합 배지 + 월령별 발달 포인트 설명). 판별 기준·근거 문서는 별도 작성 예정. 기존 월령별_발달단계_리서치·마중물 큐레이션 문서와 연결

## 5. 월령별 규칙

- 작동 방식: 점수·등급은 고정, 월령 축은 노출 제한과 경고 배지로만 작동 (①군과 동일 원칙)

| 월령 | 대상 | 규칙 | 근거 |
|---|---|---|---|
| 전 월령 (0~24개월) | 36개월 미만 사용 불가 경고 표시 제품 | 앱 전체 비노출 | KC 공통안전기준의 작은 부품 질식 경고. 베베덱스 대상이 0~2세라 해당 경고 제품은 전부 제외 |
| 전 월령 | 소형 자석·버튼전지 삽입 완구 | 점수와 무관하게 강등 + ⚠️ | 삼킴 시 장 천공·화학 화상. 소비자원·해외 리콜 다발 품목 |
| 0~5개월 | 끈·리본 길이 220mm 초과 부착 완구 | ⚠️ 경고 배지 | KC 완구 기준의 끈 얽힘·질식 항목 |
| 제품별 | 제조사 권장 월령 미달 | 해당 월령에 비노출 | 권장 월령은 안전시험의 전제 조건. 미달 사용은 시험 범위 밖 |

## 6. 계산 예시

원목 쌓기 블록, KC 안전확인, 수성도료, 열린 장난감

- 감점: 없음
- 가점: KC 안전확인 +7, 원목 +3, 수성도료 +3, 발달 가치 +3 = +16
- 점수: 70 + 16 = 86
- A 조건 미충족 (90점 미만)
- 결론: B+ 구간. 큐레이션 노출

## 7. 감점 성분별 위험 근거

| 성분·요소 | 이유 |
|---|---|
| 납·카드뮴 | 신경 발달 저해, 몸에 쌓이고 배출 안 됨. 도료·금속 부품에서 검출 |
| 프탈레이트 / PVC | 가소제와 그 주 사용 소재. 생식·발달 영향, 어린이제품 규제 대상 |
| 폼알데하이드 | 1군 발암물질. 접착제·수지에서 잔류 |
| 유성도료·VOC | 휘발성 유기화합물 방출. 입에 무는 완구에서 특히 위험 |
| 니트로사민 | 발암성 물질. 고무·라텍스 제조 과정에서 생성, 물고 빠는 과정에서 용출. EU EN 71-12가 36개월 미만 완구에 별도 기준 적용, 국내 KC 미반영이라 보수 원칙 감점 |
| PFAS | 과불화화합물. 잔류성·축적성으로 EU 신완구규정이 의도적 사용 금지. 발수·방오 코팅에 사용 |
| 향료 (EU 금지·제한 목록) | 완구 향료는 표시 의무도 없어 화장품보다 관리가 느슨. EU는 완구에 알레르기 유발 향료 금지·표시 의무 부과 |

## 8. 인증별 보증 내용

| 인증 | 가점 | 내용 |
|---|---|---|
| KC 안전인증 | +10 | 어린이제품 KC 3단계 중 최상위. 국가 지정 기관이 직접 제품 시험 + 공장 심사 |
| KC 안전확인 | +7 | 지정 기관 시험 후 성적서를 신고. 안전인증 다음 단계 |
| 유해물질 시험 통과 | +7 | 특정 항목(중금속 등)의 개별 시험 성적서 |
| KC 공급자적합성 | +5 | 제조사가 스스로 시험·확인. KC 3단계 중 가장 낮아 보증력 제한적 |
